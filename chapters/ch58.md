# 第五十八回：三山聚义打青州 众虎同心归水泊

## Core Idea
聚合势力，先给盟友出师有名的理由（大名、旧交、公仇），再给降将一个"回不了头"的投名状：呼延灼踏陷坑被擒后赚开城门，三山同归水泊；鲁智深孤身救史进，则见"必求事之必济"与"不顾事之不济"的分野。

## Frameworks Introduced
- **借兵请援的合法化**：让强援出师有名，靠口碑、旧交与公仇三合一。
  - When to use: 分散山头要请外部大队共攻一城时。
  - How: 杨志"打青州须用大队军马……呼延灼是他那里仇人……孔亮兄弟可星夜去梁山泊请下宋公明并力攻城"；鲁智深"众人说他的名字，聒的洒家耳朵也聋了"。
- **陷坑擒将**：不可力敌者，先以强将耗之、再以饵诱之、以坑伏之。
  - When to use: 吴用断"此人不可力敌，可用智擒"时。
  - How: 先令秦明与呼延灼斗四五十合不分胜败、知府鸣金；再令军校报"城北土坡有三骑看城"（宋江、花荣、道装吴用）；呼延灼"点一百马军跟我捉这三个"，追至枯树边"正踏着陷坑，人马都跌将下坑"；挠钩手钩起，花荣射倒当头五七个。
- **赚城门（降将的投名状）**：让新附者用不可逆行动自证，同时断其退路。
  - When to use: 收编敌将后要攻其旧主城池时。
  - How: 吴用"只除教呼延灼赚开城门，唾手可得，更兼绝了他的念头"；呼延灼领十头领到濠堑大叫"我逃得性命回来"，知府"只认得呼延灼声音"便开城；秦明一棍打下马，解珍解宝放火，大队拥入。

## Key Concepts
- **及时雨宋江**：江湖口碑之力——"众人说他的名字，聒的洒家耳朵也聋了"。
- **慕容知府**：青州知府、蔡太师一党，秦明仇家（"把我全家诛戮"）。
- **三山**：桃花山（李忠、周通）、二龙山（鲁智深、杨志、武松）、白虎山（孔明、孔亮），同归水泊。

## Mental Models
- 把"请援"看作合法化工程：大名、旧交、公仇三合一，盟友才出师有名。
- 把"智擒"看作预设战场的工程：饵、陷坑、挠钩手、弓箭断后，缺一不可。
- 把"救人"看作区分"不顾事之不济"与"必求事之必济"：孤勇易陷险。

## Anti-patterns
- **离城追饵**：呼延灼自称"先失地利"，却亲自开北门追三骑，踏陷坑被擒。
- **孤身造次**：武松断然不放鲁智深去，"便杀太守，也怎地救得史大官人"；鲁智深不听，独自赴华州被诱捕。

## Worked Example
孔亮至梁山哭诉叔兄被困，杨志、鲁智深请借重宋公明；宋江定五军下山。青州城下，秦明骂慕容知府"把我全家诛戮，今日正好报仇雪恨！"呼延灼迎战，斗四五十合不分胜败，知府鸣金。吴用已定"不可力敌，可用智擒"：天未明军校报城北土坡有三骑看城——宋江红袍白马、花荣、道装吴用。呼延灼"点一百马军跟我捉这三个"，悄悄开北门追上坡。三人慢慢地走，到枯树边齐齐勒住马；呼延灼刚赶到，呐声喊处"正踏着陷坑，人马都跌将下坑去了"。两侧挠钩手把他钩起绑了，花荣射倒当头五七个，余马一哄而散。宋江回寨，喝叫解了绳索，亲自扶呼延灼上帐坐定而拜，陈"权借水泊避难，只待朝廷赦罪招安"，又点破"高太尉心地匾窄……将军折了许多军马钱粮，他如何不见你罪责"，并许"宋江情愿让位"。呼延灼"一者是天罡之数，二者见宋江礼貌甚恭"，跪地"实慕兄长义气过人，愿随鞭镫，决无还理"。吴用再令他赚城门：十头领扮军士，十一骑到濠堑大叫"我逃得性命回来"，知府只认声音便开城，秦明一棍打下马，解珍解宝放火，救出孔明、孔宾，开仓散粮，三山人马尽数归山。

## Key Takeaways
1. 请外援要给理由：大名、旧交、公仇三合一，才出师有名。
2. 智擒是预设战场的工程：饵、陷坑、挠钩手、弓箭断后，缺一不可。
3. 赚城门是降将的投名状：用不可逆行动证明归属，也断其退路。
4. 救人分清"不顾事之不济"与"必求事之必济"：孤勇易陷险。
