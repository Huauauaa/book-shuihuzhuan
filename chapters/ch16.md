# 第十六回：杨志押送金银担 吴用智取生辰纲

## Core Idea
吴用破解的不是杨志的武艺而是他的警惕：先让七人当面吃光一桶酒建立安全错觉，再趁"饶瓢"之争把药抖进瓢里、由白胜劈手倾入桶中。杨志一路用藤条树威，反把十五人推到对立面——严苛管理的成本在黄泥冈一次性结清。

## Frameworks Introduced
- **双桶现场验证式下药**：用第一桶公开试吃建立"酒没问题"的错觉，第二桶在"饶瓢"动作中完成下药。
  - When to use: 目标已公开声明提防某类风险，空口保证无效。
  - How: 七人先吃一桶，刘唐"揭起桶盖，又兜了半瓢吃，故意要他们看着"；吴用"去松林里取出药来，抖在瓢里"，白胜"劈手夺来，倾在桶里"；杨志的判据正是"那桶里当面也见吃了半瓢，想是好的"。
- **提调权前置谈判**：接高风险任务前先要人事指挥权，否则宁可不接。
  - When to use: 上级加派你管束不了的人同行。
  - How: 杨志对梁中书："他是夫人行的人，又是太师府门下奶公，倘或路上与小人鳖拗起来，杨志如何敢和他争执得？"梁中书当厅分付三人"都要听他言语"，杨志方委领状。
- **严苛管理的信任透支**：用威胁换速度却不给理由、不建共识，指令终将失效。
  - When to use: 你承担全责而团队利益与你不一致时，尤其要避免。
  - How: 杨志"轻则痛骂，重则藤条便打"；老都管以资历反压"量你是个遭死的军人……芥菜子大小的官职"；行十四五日，"那十四个人，没一个不怨怅杨志"。

## Key Concepts
- **七星聚义**：晁盖、吴用、公孙胜、刘唐、三阮依次坐一至七位，应北斗七星之梦。
- **黄泥冈**：公孙胜探明"只是黄泥冈大路上来"；东十里安乐村有白日鼠白胜。
- **领状**：杨志承接押运的文书责任状，失纲后"扯破了"。
- **谢都管与两个虞候**：梁中书加派的"夫人行的人""太师府门下奶公"，同行共十五人。
- **江州车儿**：七辆贩枣子的车，事后用以装运十一担金珠宝贝。
- **"饶你奸似鬼，吃了洗脚水"**：杨志醒后自嘲的俗语。

## Mental Models
- 把"警惕"看作可被演示击穿的防线：让目标看到"别人已经安全"，胜过保证。
- 把"责任"看作必须配套权力：杨志"甘当重罪"前先要来"都听你提调"。
- 把"团队怨气"看作行动前的预警：十四人无一不怨，指令已失去执行基础。

## Anti-patterns
- **以官威压人**：老都管"量你是个遭死的军人……芥菜子大小的官职"，用资历瓦解指挥。
- **只下命令不给理由**：杨志到黄泥冈才说"这里正是强人出没的去处"，众人只当惊吓。
- **过度声明风险被反向利用**：杨志说"多少好汉被蒙汗药麻翻了"，白胜立刻以"不卖"做欲擒故纵。

## Worked Example
六月初四，黄泥冈烈日当空。杨志催军汉赶路，藤条劈头劈脑打去，众人叫"其实去不得了"；老都管又以"芥菜子大小的官职"讥他。正闹间，松林里七个贩枣子的客人推着江州车儿歇凉——正是晁盖、吴用、公孙胜、刘唐三阮。白胜挑两桶酒唱上冈来，军汉要买，杨志喝骂"多少好汉，被蒙汗药麻翻了"。七客人先买一桶，当面轮流吃尽；刘唐揭盖兜半瓢"故意要他们看着"。一人拿瓢去舀，吴用已把药抖在瓢里，白胜劈手夺过倾入桶中，骂一声"戴头识脸的，也这般啰唣"。杨志见"那桶里当面也见吃了半瓢，想是好的"，又经老都管劝，终于松口。众人先让都管、虞候吃，杨志起初不肯，天热口渴才"只吃了一半"。七客指着喝"倒也，倒也"，十五人软倒；他们把十一担金珠装上江州车，叫声"聒噪"推下冈去。杨志醒得快，扯破领状，愤闷欲跳冈寻死。

## Key Takeaways
1. 破解警惕靠现场演示，先让目标看到"别人已经安全"。
2. 接手全责任务前先谈清指挥权，否则出事无法分说。
4. 用威吓换速度会透支信任；团队怨气是失败前的信号。
