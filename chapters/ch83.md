# 第八十三回：宋公明奉诏破大辽 陈桥驿滴泪斩小卒

## Core Idea
招安后第一道考验不在外敌而在内部：童贯等瞒辽患、设计除宋江部，宿元景用"辽兵压境、官军如汤泼蚁"把屠议翻成"全伙征辽建功"；宋江在陈桥驿主动斩自己人，堵住省院问罪的口实——对外用战绩立身，对内用自切断开谗害之路。

## Frameworks Introduced
- **以患换命**：用外部更大危局，把"拆散屠灭你"翻成"派你解决危局"的任用。
  - When to use: 对方内部有人要除掉你，而另有威胁无人能解。
  - How: 宿元景先断"恩同手足，虽死不舍相离""城中翻变将何解救"，再陈辽患"申达表文求救，累次调兵如汤泼蚁，惟瞒陛下不奏"，末以"差宋江全伙建功进用，于国实有便益"收口。
- **先斩后奏式自处**：己方闯祸而对手正等借题发挥时，先处置再报备，并让担保人预先通气。
  - When to use: 下层惹祸、省院"甚是不喜我等"时。
  - How: 吴用定计"先把军校斩首号令，一面申复省院，勒兵听罪"；暗叫戴宗燕青告知宿太尉"预先奏知委曲，令中书省院谗害不得"。
- **哭着执法**：问明情节、承认环境已变，再依法处置，同时给死者体面。
  - When to use: 必须处分自己人而军心不服时。
  - How: 宋江哭"上梁山以来大小兄弟不曾坏了一个，今日一身入官，事不由我，当守法律"；令军校痛饮一醉、树下缢死斩首号令，却把厢官尸首"备棺椁盛贮"。
- **以粮为饵夺水门**：伪装粮船诱敌开"水门"，伏兵夺门。
  - When to use: 城池有水门、守敌贪功时。
  - How: 船"盖伏的好着，只扮作运粮船相似"，岸上牵拽捱到城下；诱洞仙开水门抢粮船，伏兵起而夺门；凌振炮响为号，李逵樊瑞牌手吊桥冲入。

## Key Concepts
- **破辽都先锋**：宋江受封，卢俊义副先锋，余将"待建功后加官授爵"。
- **山后九州**：辽国侵占边界，表文求救被枢密院压住不奏。
- **纳下表章不奏 / 担雪填井**：童贯蔡京高俅杨戬只行移邻近州府，瞒着天子。
- **御屏风后喝止**：宿元景把"赚入京城剿除"翻成征辽之任。
- **陈桥驿克减**：厢官把御赐酒一瓶克半瓶、肉一斤克十两。
- **斩首号令 / 勒兵听罪**：先自处分再待罪，杜人口实。
- **潞水 / 檀州 / 洞仙侍郎**：辽国紧要隘口，潞水绕城，须水陆并进。
- **没羽箭张清飞石**：一石子打中阿里奇左眼，又一石子打落耶律国宝。

## Mental Models
- 对方握程序合法性时，先主动做最严厉的自我处分，让借题发挥失去靶子。
- 把外部更大危机当杠杆：你不是威胁，你是解决威胁的人。
- 执法配套体面（醉酒、棺椁），才能压住军心成本。

## Anti-patterns
- **瞒报军情**："纳下表章不奏"如"担雪填井"，终被天子骂为"谗佞之徒、误国之辈"。
- **轻敌**：阿里奇笑"草寇何足道哉"，被张清石子打瞎左眼身死。
- **克减军赏**：被天子"暗行体察"查出，省院官"默然无言而退"。

## Worked Example
陈桥驿犒军，厢官把御赐酒一瓶克减半瓶、肉一斤克减十两。项充李衮部下一军校骂"佛面上去刮金"，厢官反骂"梁山泊反性尚不改""剐不尽杀不绝的贼"，军校一刀剁死。吴用断定"正中了他的机会"，定计先斩首号令、申复省院、勒兵听罪，再暗叫戴宗燕青告知宿太尉。宋江飞马到驿，先搬酒肉如数赏三军，再问军校情节；听他说是被骂"千梁山泊反贼"才动手，哭道"今日一身入官，事不由我，当守法律"。令其痛饮一醉、树下缢死、斩首号令，却把厢官尸首备棺椁盛贮。次日天子反责省院"委用不得其人"，只把宋江"禁治不严之罪权且纪录"，催他提兵破辽。一场自断，堵住了谗害之路。

## Key Takeaways
1. 对方握程序合法性时，先主动自我处分，让借题发挥失去靶子。
2. 外部更大危机是翻转内部迫害的杠杆。
3. 执法配套体面（醉酒、棺椁）才能压住军心成本。
4. 强将不可轻敌；飞石补位能一击定胜负。
