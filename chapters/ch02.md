# 第二回：王教头私走延安府 九纹龙大闹史家村

## Core Idea
权力落在"管你的人"手里时，官阶毫无意义——高俅靠蹴鞠发迹、掌权即报私仇，逼走王进；史进以义气放走少华山三寇，赢得声望也埋下泄密围庄的祸根。关系网络的亲疏与管辖权的落点，比才能更决定命运。

## Frameworks Introduced
- **帮闲发迹链**：浮浪子弟以才艺贴附权贵、层层转荐，得宠授官后以官报私仇。
  - When to use: 分析非正式权力绕过资历上位。
  - How: 高俅走被害→赌坊柳世权→董将仕→小苏学士→小王都太尉→端王；关键一跃是"鸳鸯拐"踢还气毬。
- **"不怕官，只怕管"**：威胁你的不是官阶最高者，而是握直接管辖权的顶头上司。
  - When to use: 评估组织中的报复风险。
  - How: 先问"此人是否属他管"，再问"有无旧仇"——王进认出高俅即知性命难保。
- **支开监视者的"走为上着"**：给看守者分配错时且互不重叠的任务。
  - When to use: 需携家脱身而不能惊动看守。
  - How: 先遣张牌去岳庙烧头香，再遣李牌送银买三牲，自己五更备马扶母上马，弃粗重锁门出西华门。
- **"大虫不吃伏肉"的义气豁免**：对手示弱诉诸义气，杀之反被视为不英雄。
  - When to use: 已擒敌手、处置影响声望时。
  - How: 朱武、杨春跪地流泪称"不求同日生，只愿同日死"；史进权衡后放人。

## Key Concepts
- **高俅（高毬）**：东京帮闲破落户，善踢气毬，因端王宠信擢殿帅府太尉。
- **王进**：八十万禁军教头，因高俅旧仇弃家私走延安府。
- **老种经略相公**：镇守延安府边庭的边帅，王进投奔处。
- **九纹龙史进**：身刺九条青龙，拜王进为师学全十八般武艺。
- **少华山三寇**：神机军师朱武、跳涧虎陈达、白花蛇杨春。
- **摽兔李吉与赛伯当王四**：告密者与醉酒失书的庄客，共酿中秋围庄。

## Mental Models
- 把"管辖关系"看作比"官阶"更真实的权力：成为顶头上司那刻，倒计时开始。
- 把"义气"看作双向社会资本：放人换声望与金银，也因往来过密而暴露。
- 把"脱身"看作信息战：王进用时间差制造真空，史进让醉汉独携密信。

## Anti-patterns
- **把看守者当自己人**：王进靠"分而遣之"成功，史进让王四独携回书而失败。
- **自作主张的隐瞒**：王四谎称"何必回书"，反把把柄交给李吉。
- **低估旧仇**：王进认出高俅后拖到当众受辱才决断。

## Worked Example
陈达不听朱武、杨春劝阻，下山先打史家村，被史进卖破绽一挟活捉，绑在庭心柱上。杨春欲全伙"死并"，朱武定下"苦计"：二人步行至庄前双双跪地流泪，诉"不求同日生，只愿同日死"，请史进把三人一并解官、"就英雄手内请死"。史进寻思若拿去请赏，反教天下好汉耻笑不英雄——"大虫不吃伏肉"，遂解放陈达、设席管待。朱武等回寨十余日送三十两蒜条金谢恩，此后金银往来不绝；直到中秋王四醉卧林中失落回书，被摽兔李吉拾去出首，华阴县县尉引兵围庄，史进不得不杀开一条路。

## Key Takeaways
1. 判断报复风险，先确认对方是否有直接管辖权，而非只看官阶。
2. 脱身要给看守者错时且互不重叠的任务，而非同时打发。
3. 处置已擒的对手先问声望成本：示弱者杀之无名，放之可得人心。
4. 密信与证人最脆弱，绝不可交予醉汉独行。
