# 第八十八回：颜统军阵列混天象 宋公明梦受玄女法

## Core Idea
太乙混天象阵按周天星象、聚阳象，正面"只此攻打永不能破"，宋江连撞四次皆败；破法不在勇力而在"相生相克"的结构映射——用颜色星宿对应五行逐层拆解，再以雷车与风雷天罡正法直捣中军。

## Frameworks Introduced
- **识阵不可造次**：朱武认得"太乙混天象阵"，断"变化无穷，交加莫测，不可造次攻打"；吴用竟不识。
  - When to use: 对方阵势宏大、结构复杂时。
  - How: 先识阵，承认"不知他阵内虚实"便不可打；宁可"深栽鹿角，坚闭不出，且过冬寒"。
- **纯交换换俘**：宋江只做一对一的"同收同放"。
  - When to use: 己方要人被俘、对方亦在你手中时。
  - How: 不夹带"罢战"条件（兀颜统军以"束手来降"相挟），只约"可放过俺的头目来，我还你小将军"，当日不厮杀。
- **不识勿逞**：王文斌"自己不识，且图诈人要誉"，看一回便说"只如常"，出阵被诱赶身死。
  - When to use: 空降专家不了解实际对手时。
  - How: 反面案例——先看懂再出手；见番将"回身便走"便骤马直赶，正合"特地要卖个破绽"。
- **相生相克破阵（玄女法）**：按五行对应颜色星宿，层层克制，夜袭中军。
  - When to use: 敌方阵法按五行星象组织、正面强攻无效时。
  - How: 皂旗水星用七员黄袍将撞七门、一员黄袍直取水星（土克水）；白袍八员打青旗（金克木）、红袍八员打白旗（火克金）、皂旗八员打红旗（水克火）、青旗九员取中央黄旗（木克土）；绣旗扮罗㬋破太阳、素袍扮计都破太阴；二十四部雷车推入中军，公孙胜风雷天罡正法奔国主驾前；"日间不可行兵，须是夜黑可进"。

## Key Concepts
- **太乙混天象阵**："聚阳象也"，"如鸡卵之形，团团似覆盆之状，旗排四角，枪摆八方"。
- **六队游兵**：每队五百，左三右三循环往来，"又号哨路，又号压阵"。
- **四军七门**：皂旗（北）、青龙旗（东）、白虎旗（西）、绯红旗（南），按二十八宿分段。
- **四把总**：曲利出清（玄武水星）、只儿拂郎（苍龙木星）、乌利可安（咸池金星）、洞仙文荣（朱雀火星）。
- **太阳 / 太阴**：御弟耶律得重、天寿公主答里孛，各领五千。
- **兀颜光**：中央镇星／中宫土星一炁天君，"暗合璇玑玉衡、乾坤混沌之象"。
- **天盘左旋**："今日属金，天盘左动，必有兵来"，五炮齐响、金星引四宿卷杀。

## Mental Models
- 按"象"组织的系统，破法要在同构的符号层面找克，不是加大正面兵力。
- 识不透的复杂系统，先"坚闭不出"，比反复撞击更省。
- 空降专家没看懂就说"不过如此"，卖破绽的人正等你追。

## Anti-patterns
- **不识强攻**：朱武已言"不可造次攻打"，宋江仍四次撞阵，李逵被捉、王文斌身死。
- **图誉轻敌**：王文斌看一回便说"只如常"，二十合被诱赶背砍。
- **时辰失当**：玄女明示"日间不可行兵，须是夜黑可进"——时辰也是阵法的一部分。

## Worked Example
宋江连败数阵、李逵被活捉、王文斌被曲利出清背砍身死。是夜二鼓狂风冷气，青衣女童奉娘娘法旨引他过石桥棂星门入殿见九天玄女。玄女问"吾传天书与汝不觉又早数年，今宋天子令汝破辽，胜负如何"，宋江俯伏奏称被混天象阵累败无计可施。玄女道"此阵聚阳象也，只此攻打永不能破；若欲要破，须取相生相克之理"，遂授五色军马克四门、罗㬋计都破太阳太阴、二十四部雷车与公孙胜风雷天罡正法，又戒"日间不可行兵，须是夜黑可进，汝当亲自领兵掌握中军"。青衣一推，宋江惊觉，更鼓已四更。他请吴用圆梦，称"已梦玄女娘娘传与秘诀"，会集诸将分拨。

## Key Takeaways
1. 按"象"组织的系统，破法要在同构符号层面找克。
2. 识不透的复杂系统，先坚闭不出，比反复撞击更省。
3. 换俘去掉附加条件，只做"同收同放"的最小交换。
4. 突破性方案来自体系外，但要翻译成颜色、人数、时辰等参数。
