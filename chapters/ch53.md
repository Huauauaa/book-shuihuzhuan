# 第五十三回：戴宗智取公孙胜 李逵斧劈罗真人

## Core Idea
请人不是把人说服，而是打通他背后的授权链：公孙胜推母老、推师命，戴宗设下让李逵"逼"、让真人"许"的两级跳；李逵这个不可控变量，最终也被幻术驯服——不是打服，是让他自己"不敢了也"。

## Frameworks Introduced
- **神行法的行为契约**：先立规矩，再用可控后果惩处违约。
  - When to use: 带强力却不守令的同伴长途办事时。
  - How: 戴宗约"一路上吃素，都听我的言语"；察觉李逵偷吃牛肉不当场戳破，次日拴四个甲马作法"行八百里便住"，谎称"吃了一块牛肉只要走十万里方才得住"，待其发誓才喝"住"，此后只缚两个甲马。
- **激将请人的分工**：文者守礼赔话、武者破门逼出，边界是"不得伤犯他老母"。
  - When to use: 对方推说不在家、礼请被挡回时。
  - How: 戴宗入见婆婆被推"出外云游"，便对李逵说"他若说不在时你便打将起来，却不得伤犯他老母"；李逵插斧威胁烧屋、砍翻一堵壁，公孙胜现身喝"不得无礼"。
- **师门请命的授权链**：个人不肯，真正卡住他的是家庭责任与师命。
  - When to use: 关键人物有"母老、师留"双重约束时。
  - How: 公孙胜"一者母亲年老，二乃本师罗真人留在座前"；戴宗从苦告升级到"山寨大义从此休矣"，公孙胜才许"禀问本师"；罗真人两拒后终以"大义为重，权教他去走一遭"。

## Key Concepts
- **戴宗／神行太保**：拴甲马作神行法，"要行便行，要住便住"；以八百里、十万里之罚立规。
- **清道人**：公孙胜隐居名号，"此是俗名，无人认得"；罗真人上首徒弟，在屋后炼丹。
- **罗真人**：紫虚观松鹤轩云床上的得道真人，手帕化红青白云，有黄巾力士千馀员。
- **天杀星**：李逵"上界天杀星之数，为是下土众生作业太重，故罚他下来杀戮"。
- **妖人李二**：李逵在蓟州府被马知府屈打成招的化名。

## Mental Models
- 把"神行法"看作带约束的自由：守规矩才能"要住便住"。
- 把"激将请人"看作分工：一人赔话守底线，一人制造代价逼其现身。
- 把"不肯去"拆成本人意愿、家庭责任、师门授权三层，逐层打通。

## Anti-patterns
- **偷吃牛肉**：戴宗明戒牛肉，李逵背着吃，被甲马作法规矩一日一夜脚不点地。
- **夜斧劈真人**："你原是山寨里人，却来问甚么鸟师父！" 自作主张杀人，其实只砍了两个葫芦。

## Worked Example
戴宗、李逵到蓟州寻了两日无果。素面店里李逵拍桌溅了老人一脸热汁，戴宗陪话，那老人是九宫县二仙山下人氏，回去听罗真人讲长生之法；戴宗得知公孙胜改名清道人，隐居二仙山。戴宗先入见婆婆求见，被推"出外云游"，便唤李逵"他若说不在时你便打将起来，却不得伤犯他老母"。李逵插斧威胁烧屋、砍翻一堵壁、惊倒婆婆，公孙胜现身喝"不得无礼"。公孙胜以母老、师命推辞，戴宗苦告到"山寨大义，从此休矣"，方许禀问本师。上紫虚观，罗真人两番不肯。三更李逵摸上山，舐破窗纸，提斧把"真人"劈倒云床、又砍倒"童子"；天明三人再上山，罗真人仍端坐云床，李逵惊得舌头半日缩不回。真人以手帕化云载三人，笑说"只是砍了我两个葫芦，其心不善，且教你吃些磨难"，一阵恶风把李逵吹落蓟州府厅，淋狗血尿屎、枷下大牢。戴宗在观中日夜磕头求了五日，真人本要驱除，听他数李逵"耿直、不阿谄、无淫欲贪财"三长，方差黄巾力士取回。李逵见真人只管磕头："铁牛不敢了也！"

## Key Takeaways
1. 带强力而违纪的同伴：先立约、再用可控后果惩戒，胜过说教。
2. 礼请无效可用"分工式施压"：一人守礼赔话，一人制造代价。
3. 说服关键人物要找到真正的授权人——父母、师门。
4. 面对不可控的暴力，让它撞上更高秩序，比正面压制代价小。
