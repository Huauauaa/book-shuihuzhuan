# 第六回：九纹龙剪径赤松林 鲁智深火烧瓦罐寺

## Core Idea
遇"两边各有说辞"的残局，智深先被表面礼貌误导而败走，再靠同伴与饱食翻盘；大相国寺则用"一年一升"的职事阶梯，把一个刺头放进最脏的坑里——把边缘岗位设计成有出口的通道，才是安置异类之道。

## Frameworks Introduced
- **证词的反证**：两方各执一词时，用对方戒备行为验证谁说谎。
  - When to use: 信息矛盾、无法当场分辨。
  - How: 老僧点破"他见你有戒刀禅杖，不敢与你相争"；智深再去时角门已关、崔道成持朴刀抢出，谎言不攻自破。
- **败走重整**：体力、路程、人数三劣势叠加，退出是理性选择。
  - When to use: 条件不利且还有资源未取回。
  - How: 智深"肚里无食、走了许多路途、当不的他两个生力"，卖破绽拖杖便走；赤松林从史进处得干肉烧饼吃饱，同回后八九合把崔道成打下桥。
- **职事晋升阶梯**：把末等岗位纳入"一年一升"的可预期序列。
  - When to use: 安置难以直接重用的人。
  - How: 知客说明管菜园是"头事人员，末等职事"，一年升塔头、又一年升浴主、又一年升监寺；智深遂从"如何教洒家去管菜园"转为"洒家明日便去"。

## Key Concepts
- **瓦罐寺**：十方常住古刹，被生铁佛崔道成与飞天夜叉丘小乙占据，殿宇崩损。
- **生铁佛崔道成／飞天夜叉丘小乙**：冒作出家人的强贼，"把这出家影占身体"。
- **赤松林剪径**：史进在此寻盘缠，靠"声音好熟"与智深剪拂相认。
- **大相国寺**：东京名刹，智清禅师住持，智真荐书称智深"久后正果非常，千万容留"。
- **职事等级**：清职、掌常住财物、主事、头事（塔头、饭头、茶头、菜头、净头）。
- **酸枣门外菜园**：大相国寺产业，被泼皮偷菜骚扰，智深受委住持。

## Mental Models
- 把"证词冲突"看作可用行为验证：谁关门、谁持刀，比谁客气更可信。
- 把"败走"看作资源重整——吃饱、找到同盟，再战自然"得便处一禅杖"。
- 把"低微岗位"看作有上升序列的起点：先确认规则，再决定接受。

## Anti-patterns
- **被"小心"话术误导**：崔道成自辩让智深一度反骂老僧说谎。
- **劣势下硬拼**：饥饿、长途、二打一叠加仍恋战，第一战必败。
- **轻信"作庆"的礼貌**：泼皮笑脸、果盒酒礼，却是粪窖伏击的前奏。

## Worked Example
智深投瓦罐寺讨斋，寻出老僧藏的粟米粥，听他们三日无饭便撇下不吃。崔道成反称寺被老僧败坏、妇人只是檀越之女，智深信而回骂老僧；老僧点破"他见你有戒刀禅杖，不敢与你相争"，智深再去时角门已关，崔道成持朴刀抢出、丘小乙背后夹击，智深饥疲交加败走，包裹落在寺里。行至赤松林遇剪径汉子，斗十数合听声音厮熟，通名原是史进，二人剪拂，史进以干肉烧饼饱其饥。同回瓦罐寺，智深得饱食胆壮，八九合把崔道成打下桥，史进跳出望后心一朴刀搠死丘小乙。二贼尸首撺入涧中，老僧已吊死、妇人投井，包裹原封未动。二人取金银、吃饱，缚火把烧寺，"梁园虽好，不是久恋之家"，连夜赶路；村店中史进决定回少华山入伙，智深分金银，三岔路分手投东京。

## Key Takeaways
1. 判断两方说辞，看谁关门、谁持器械，行为比语气诚实。
2. 饥饿疲劳人数劣势时果断退出，先补资源再翻盘。
3. 安置刺头型下属，给有出口的晋升阶梯比直接重用有效。
4. 离开败局要收尾干净：包裹原封、尸首处理、一把火断后患。
