# 第八回：林教头刺配沧州道 鲁智深大闹野猪林

## Core Idea
加害不必亲自动手：孙定在开封府把"故入节堂"改成"误入节堂"保住一命；陆谦则用十两金子把杀意外包给公人，靠"上司差遣"的话术与"金印回话"的凭证完成可复制的谋杀。制度允许把人"合法"交出去时，执行者只需一句"不由自己"。

## Frameworks Introduced
- **换罪名的转圜**：不否认事实，只改换主观动机，在权势与法度间找中间判词。
  - When to use: 上级定调重办但证据站不住。
  - How: 孙定承认"腰悬利刃"入堂，把"故入节堂杀害本官"改为"误入节堂"，判脊杖二十、刺配远恶军州；以"这南衙开封府不是朝廷的，是高太尉家的？"顶住府尹，高俅情知理短只得准。
- **休书的风险切割**：预知家人将被骚扰，先用文书断开名义关系。
  - When to use: 即将长期失势、对方能接触家人。
  - How: 林冲当众立纸"任从改嫁，永无争执"，写明"委是自行情愿，即非相逼"，请丈人邻舍作证；张教头却以"我只不把女儿嫁人便了"抵消其效力。
- **买凶的外包链**：以心腹身份付钱、给话术、要凭证，使加害像公差。
  - When to use: 拆解"执行者自称奉命"的伤害。
  - How: 陆谦各送五两金子，要董超薛霸"只就前面僻静去处把林冲结果了"，"揭取脸上金印回来做表证"，另许十两；薛霸以"高太尉便叫你我死也只得依他"说服董超。

## Key Concepts
- **孙定（孙佛儿）**：开封府当案孔目，鲠直好善，以"误入节堂"改判救人。
- **脊杖二十、刺配沧州**：刺面称"打金印"，佩"七斤半团头铁叶护身枷"。
- **董超、薛霸**：防送公人称"端公"；董先顾虑、薛先收金，一推一就。
- **张教头与休书**：林冲丈人收下休书却坚持不嫁女。
- **陆虞候**：自称"高太尉府心腹人"，买通公人、索取金印回话。
- **野猪林**：东京往沧州第一险处，"不知结果了多少好汉"的制度化暗杀地点。

## Mental Models
- 把"司法转圜"看作改换罪名而非否认事实：承认行为，改写动机。
- 把"休书"看作单方风险切割文书：效力取决于执行者是否配合。
- 把"野猪林"看作制度化暗杀节点：地点＋公人＋金钱＝可复制流程。

## Anti-patterns
- **以"为你好"替他人决定**：林冲立休书，娘子哭"我不曾有半些儿点污，如何把我休了"，哭倒。
- **半推半就即入局**：董超说"公文只叫解活的去"却仍分金同行。
- **"不由自己"的话术**：把个人选择包装成奉命。

## Worked Example
改判后林冲刺配沧州，董超薛霸押解。州桥酒店里，林冲当着丈人与邻舍立休书"任从改嫁，永无争执"，自称"非他人逼迫"；娘子赶到哭诉"我不曾有半些儿点污，如何把我休了"，听罢休书哭倒在地。另一边陆虞候在酒店各送五两金子，要二公人"只就前面僻静去处把林冲结果了"，揭取脸上金印作表证。六月炎暑，林冲棒疮发作；村店中薛霸灌醉他，烧百沸滚汤按其双脚泡红肿，次日逼穿麻编新草鞋，三五里便血肉淋漓。行至野猪林，二公人称"只怕你走了，我们睡不稳"，把林冲连手带脚和枷绑在树上，明言"陆虞候传着高太尉钧旨，教我两个到这里结果你，立等金印回话""明年今日是你周年"。林冲泪如雨下求救，董超只答"救你不得"。薛霸提起水火棍劈头下来——本回至此戛然而止。

## Key Takeaways
1. 证据站不住时，改换罪名比正面抗辩更易守住底线。
2. 替家人"预先切割关系"前，先确认对方是否愿意被你代表。
3. 执行者说"奉命、不由自己"时，看他收了什么、要交回什么凭证。
4. 熟悉"惯发地点"的风险，比相信同路人承诺更可靠。
