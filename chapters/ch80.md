# 第八十回：张顺凿漏海鳅船 宋江三败高太尉

## Core Idea
高俅在诏书上用"除宋江"断句设陷阱，吴用、花荣当场识破一箭反击；他又不听闻焕章"不可亲登水路"之谏，登上叶春所造海鳅船，结果水车被填、船底被凿，被张顺从水底揪下船生擒。宋江不杀不辱、换衣下拜、尽放俘虏，只求一句"回朝保奏招安"——三败高俅，目的仍是招安。

## Frameworks Introduced
- **识破文本陷阱**：听出诏书断句藏刀，用行动而非申辩回应。
  - When to use: 对方在文书措辞上做手脚时。
  - How: 诏书"除宋江，卢俊义等大小人众所犯过恶，并与赦免"；吴用"正听读到'除宋江'三字，便目视花荣道：'将军听得么？'"；花荣"既不赦我哥哥，我等投降则甚！""看花荣神箭！"一箭射中使臣面门。
- **薅恼船厂**：不在水上硬碰新船，而在造船阶段纵火并多处起火分散救兵。
  - When to use: 敌方赶造大型装备、尚未成军时。
  - How: 吴用"先教一两个弟兄去造船厂里薅恼他一遭"；时迁、段景住待船厂火起后去城楼、西草场各放一把火，"教他两下里救应不迭"；张清五百骠骑伏兵杀出，一石子打中丘岳面门。
- **凿漏海鳅船**：大船依赖水车空间与完好船底，两者皆被水下作业破坏。
  - When to use: 敌方船大、连锁、机动依赖水车时。
  - How: "水车正要踏动时，水底下都填塞定了，车辐板竟踏不动"；"张顺引高手水军把锤凿凿透船底"，前后船尽沉；张顺从水底钻上柁楼揪住高俅喝"下去！"把他丢下水——"浑如瓮中捉鳖"。

## Key Concepts
- **天诏黄旗**：济州只北门立黄旗书"天诏"；宋江坚持"唤耆老听诏"才卸甲。
- **除宋江断句**：王瑾献计把赦免对象从宋江剥除；吴用花荣识破。
- **叶春 / 海鳅船**：泗州造船人，献大海鳅船（二十四部水车）。
- **浪里白跳张顺**：水下凿船、揪高俅丢下水，"水里拿人，浑如瓮中捉鳖"。
- **守命扑**：燕青把自夸"相扑无对"的高俅一交攧翻在地褥上。
- **萧让 / 乐和**：随高俅入京；闻焕章留梁山为信。

## Mental Models
- 文书陷阱要用当场行动回应，不陷在字面申辩里。
- 大船的脆弱点在系统前提：填塞水车、凿穿船底，再大的船也坐着沉。
- 生擒主帅是谈判资产：不杀、换衣、下拜、放人，换"回朝保奏"的承诺。

## Anti-patterns
- **断句害人**：王瑾"除宋江"另做一句，当场被识破，反招"射死天使"之祸。
- **主帅亲临险地**：闻焕章谏"不可自登水路"，高俅"今次正要与贼人决一死战"。
- **酒后自夸**：高俅夸相扑天下无对，被燕青一交攧翻，"惶恐无限"。

## Worked Example
高俅不听闻焕章"不可亲登水路"之谏，亲率海鳅船队杀入梁山深处。阮氏三雄、孟康童威童猛、李俊张横张顺三批小船接连"被夺"——好汉们或披金银箔纸甲、或抹粉披发，官军一放火器便弃船跳水，只夺得空船，却一步步被引到深处。山顶号炮连珠，芦苇中千百小船如飞蝗钻出：大海鳅撞不得，水车被水底填塞"车辐板竟踏不动"，弩楼放箭则小船人"自顶片板遮护"；挠钩搭柁、板刀砍踏车军士，前后船被塞住进退不得。舱内齐喊"船底漏了！"——张顺引高手水军凿透船底，前后船尽沉。高俅扒上柁楼，张顺从水底钻起，揪巾帻束带喝"下去！"，把他丢下水。丘岳被杨林砍下船，单走周昂、王焕、项元镇、张开四人。宋江见高俅"慌忙下堂扶住"，换衣请上坐、纳头便拜"死罪"，传令不许杀人、尽放军士回济州，只求他"回朝重奏，请降宽恩大赦"——三败之后，要的仍是一纸招安。

## Key Takeaways
1. 文书陷阱用当场行动回应，不陷在字面申辩里。
2. 敌方赶造大型装备时，最省的破坏在造船厂：多处纵火、分头救应。
3. 大船的脆弱点在系统前提：填塞水车、凿穿船底，再大也坐着沉。
4. 俘获关键人物是谈判资产：不杀、换衣、下拜、放人，换"回朝保奏"。
