# 第十四回：赤发鬼醉卧灵官殿 晁天王认义东溪村

## Core Idea
晁盖救刘唐靠"身份重构"：先调虎离山隔开看守，再用可核实的局部特征（鬓边朱砂记）与自洽时间线把陌生人认作外甥王小三，并以假意责打做足表演；吴用则凭"亲眷底册与年甲不符"识破蹊跷，却先劝架不站队。

## Frameworks Introduced
- **临时亲属身份的解围术**：被误抓时，把陌生人身份换成盘查者能接受的亲属关系。
  - When to use: 需即时脱身，且盘查者与你熟识、愿给面子。
  - How: 晁盖授计"你只认我做娘舅之亲……叫我做阿舅"，公开场合以"鬓边有这一搭朱砂记，因此影影认得"作验证，并夺棍"劈头劈脸便打"、骂其贪酒，把戏做足。
- **调虎离山式接触**：先把看守者引开，再接触被押者。
  - When to use: 当着看守面谈会被听见。
  - How: 晁盖请雷横到后厅吃酒、"叫置酒与土兵众人吃"，庄客引众人去廊下；自己"拿了个灯笼，径来门楼下看"，门房外已无人。
- **团队规模的黄金区间**：人多做不得，人少又做不得。
  - When to use: 策划高风险、需保密的行动。
  - How: 吴用判断"庄客一个也用不得……须得七八个好汉方可，多也无用"，以晁盖"梦见北斗七星"暗合人数。

## Key Concepts
- **赤发鬼刘唐**：东潞州人，紫黑阔脸、鬓边朱砂记；来投晁盖献"一套富贵"。
- **托塔天王晁盖**：东溪村保正，仗义疏财；曾独夺西溪村青石宝塔放到东溪边。
- **灵官殿**：雷横巡捕见殿门不关、供桌上赤条条睡着大汉，把人绑了。
- **王小三**：晁盖临时编出的外甥名，"四五岁随家姐夫上南京去住"。
- **智多星吴用**：表字学究，道号加亮先生；手提铜链隔斗。
- **北斗七星梦**：晁盖梦七星坠屋脊、斗柄小星化白光，被引为聚义人数之兆。
- **不义之财**：梁中书十万贯送蔡太师庆生辰；刘唐"取而何碍"。

## Mental Models
- 把"被误认"看作身份重构题：具体特征＋自洽时间线＋情绪表演，胜过空口辩解。
- 把"看管"看作空间问题：先把看守者请离现场，接触才安全。
- 把"行动人数"看作倒U型：少则担不起，多则泄密——本案判据是七八人。

## Anti-patterns
- **事后邀功式冒险**：刘唐为"夺回银子送还晁盖，他必然敬我"，独自持朴刀追雷横，斗五十馀合几乎丧命。
- **贪杯致暴露**：昨夜路上多吃一杯酒，权去庙里睡，被拿作贼。
- **把"不义之财"当免责**：道义上"取而何碍"成立，仍须"商议个道理"。

## Worked Example
雷横在灵官殿绑了赤条条大睡的刘唐，押到东溪村晁保正庄上讨点心。晁盖把雷横与土兵请到后厅、廊下吃酒，自己提灯笼去门房，见那汉紫黑阔脸、鬓边一搭朱砂记。刘唐说特来投奔晁保正、送一套富贵。晁盖当场授计："你只认我做娘舅之亲……叫我做阿舅。"回厅陪酒到天明，雷横辞行，土兵解出刘唐，刘唐叫"阿舅救我"；晁盖假意喝问"兀的这厮不是王小三么"，以朱砂记"影影认得"，又夺棍劈头劈脸便打，骂他贪酒不径来见。雷横劝住解绑，晁盖送十两花银并赏土兵。随后换衣问名，刘唐自报赤发鬼，献梁中书十万贯生辰纲之谋——"此是一套不义之财，取而何碍！"晁盖只答"壮哉！且再计较"，先安置客房。

## Key Takeaways
1. 被误认时不要空口辩解，给可核实的具体特征与自洽时间线。
2. 需私下接触被扣留者时，先把看守者请离现场。
3. 掌握内情的人先叫停冲突，比急着站队更能看清真相。
4. 高风险行动人数要限定在"少则担不起、多则泄密"的区间。
