# 第三回：史大郎夜走华阴县 鲁提辖拳打镇关西

## Core Idea
侠义落地靠三步：先拆结构、再造理由、留好退路。鲁达先筹银送走金氏父女、坐镇店中阻断追兵，再以买肉刁难逼郑屠先动刀，占住"理"与"势"后出手；但报复强度一旦启动便无精确刻度，"痛打一顿"变成三拳毙命。史进以"清白好汉"自守，宁可流亡也不肯点污父母遗体。

## Frameworks Introduced
- **先占理、后动手**：激对方先失态出手，自己再反击，旁观者便不敢劝阻。
  - When to use: 当众惩戒有势力、有靠山的人。
  - How: 鲁达借"经略相公钧旨"三次刁难——十斤精肉、十斤肥肉、十斤寸金软骨，皆切臊子；逼郑屠说"却不是特地来消遣我"，鲁达接"洒家特地要消遣你"，劈面打去诱其持刀跳出。
- **救助的三段式**：筹款脱身→阻断追兵→再报仇。
  - When to use: 救助被债务与势力双重控制的人。
  - How: 鲁达自摸五两、向史进借十两、李忠二两嫌少丢还，共十五两与金老；次日亲送出城，掌掴店小二后"掇条凳子坐了两个时辰"。
- **"诈死"脱身话术**：失手致死后以反语制造对方未死假象，争取逃离窗口。
  - When to use: 后果不可逆、围观者不敢拦时。
  - How: 鲁达见郑屠面皮变色，假意道"你这厮诈死，洒家再打"，一头骂一头大踏步走，回下处卷细软、提短棒出南门。

## Key Concepts
- **鲁达／鲁提辖**：渭州经略府提辖，曾任关西五路廉访使，性粗卤而急公好义。
- **镇关西郑屠**：状元桥下卖肉屠户，投托经略府做肉铺户。
- **金翠莲与金老**：流落渭州的唱曲父女，被郑屠"虚钱实契"写三千贯强占又驱逐。
- **虚钱实契**：立据三千贯却未得一文，据此追债的制度性外衣。
- **打虎将李忠**：史进开手师父，摸出二两银被鲁达嫌"不爽利"丢还。
- **海捕文书**：写年甲贯址、画影图形、赏钱一千贯的四处追捕文书。

## Mental Models
- 把"动手"看作需"占理"的流程：先让对方失态先出手，旁观者才不干预。
- 把"仗义"看作先拆散受害者困境结构——给钱、挡人、留时间窗。
- 把"清白"看作身份资产：史进宁可流亡也不肯点污父母遗体，是与草寇的分界。

## Anti-patterns
- **不爽利的救助**：李忠二两被丢还——吝啬既救不了人，也失江湖信任。
- **以讨饶求免**：郑屠讨饶反触"硬到底倒饶你，讨饶却不饶你"，惩罚升级。
- **误判报复强度**："只指望痛打一顿"，三拳真打死——暴烈无精确刻度。

## Worked Example
潘家酒楼上，鲁达听金氏父女啼哭，问出郑屠"虚钱实契"强占翠莲又迫还三千贯，拍桌要打死那厮，被史进、李忠劝住。他先筹资十五两送金老还乡，次日亲至客店催其起身，一掌打得店小二口吐血，又掇凳坐镇两个时辰。估其远去，鲁达到状元桥郑屠肉案前，借钧旨要十斤精肉、十斤肥肉、十斤寸金软骨切臊子。郑屠笑"却不是特地来消遣我"，鲁达应"洒家特地要消遣你"，将两包臊子劈面打去。郑屠抢剔骨尖刀跳出，被鲁达按住左手、一脚踢倒，踏住胸脯骂"狗一般的人也叫做镇关西"，三拳打在鼻、眼棱、太阳，似油酱铺、彩帛铺、水陆道场。见其面皮变色，假称"诈死"大步走脱，卷细软提短棒出南门。

## Key Takeaways
1. 惩戒有靠山的对手，先激其先动手，把"理"与"势"握在手里。
2. 救人先拆结构：资盘缠、断追兵、留时间窗，再论报复。
3. 冲突前预设退出机制——"诈死"话术争取了逃离时间。
4. 别以为"打一顿"可控：强度一旦启动便无刻度，三拳足以毙命。
