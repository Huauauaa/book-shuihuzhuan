# 第八十四回：宋公明兵打蓟州城 卢俊义大战玉田县

## Core Idea
分兵深入陌生地理，朱武用"击首则尾应"的长蛇阵补上首尾不能救应；卢俊义玉田县被围，靠事先埋进城内的石秀、时迁四处纵火"里应外合"才解围——攻坚关键不在云梯火炮，而在提前埋设信息节点；张清中"一点油"冷箭，说明最强的单点手段也有天敌。

## Frameworks Introduced
- **长蛇之势**：朱武"未知他地理，诸军不可擅进，可将队伍摆为长蛇之势，击首则尾应，击尾则首应，击中则首尾相应，循环无端"。
  - When to use: 分兵进入陌生地带、各部可能被冲散时。
  - How: 以长蛇阵部署，使任一点受击都能首尾相救。
- **识阵变阵**：朱武上云梯看辽兵"五虎靠山阵，不足为奇"，上将台号旗招动自摆"鲲化为鹏阵"——"远观近看只是个小阵；若来攻时，一发变做大阵"。
  - When to use: 两军对垒、敌方先列阵时。
  - How: 先登高识阵（云梯），再以旗号调拨变阵（将台）。
- **预伏内应、以火为号**：借本地人潜入城中，约塔上起火为号配合攻城。
  - When to use: 坚城紧闭、强攻不下时。
  - How: 公孙胜蓟州人、杨雄曾做节级、石秀时迁住久，扮败残军马杂入城中；时迁躲宝严寺宝藏顶上，石秀送饭并去州衙放火，"只等城外打得紧急时，塔上放火为号"。
- **冷箭破飞石**：败卒认出张清，天山勇以"一点油"漆抹弩设伏。
  - When to use: 敌方有百发百中的单点王牌时。
  - How: 借檀州败卒指认"穿绿战袍的蛮子"；天山勇令两副将影射、三骑悄悄趱近；趁张清石子擦盔时一箭射中咽喉。

## Key Concepts
- **赵安抚**：枢密院同知，宽仁厚德，宿太尉保奏，赍赏赐二十五车监战。
- **蓟州 / 玉田县**：蓟州乃辽国库藏，"钱粮极广，米麦丰盈"。
- **御弟大王耶律得重**：守蓟州，四孩儿宗云、宗电、宗雷、宗霖。
- **五虎靠山阵 / 鲲化为鹏阵**：朱武识破前者，摆后者，小阵变大阵。
- **一点油**：天山勇惯使的漆抹弩、一尺铁翎箭。
- **张清中箭**：咽喉中箭，安道全调治，"外损皮肉，却不伤内"。
- **燕青回礼**：弩射耶律宗云鼻凹，"昨日张清中他一冷箭，今日回礼则个"。
- **宝严寺**：塔上放火为号，石秀时迁功次标写。

## Mental Models
- 陌生地理下，"首尾相应"的阵形比单点骁勇更能防崩盘。
- 坚城不下时，提前埋本地人当信息节点、用火光当信号，比堆云梯更省。
- 超级手段必有天敌：飞石怕冷箭；王牌暴露后要立刻换打法。

## Anti-patterns
- **不识地理擅进**：卢俊义"吴人不识越境，到他地理生疏"，朱武戒"不可擅进"。
- **暴露王牌**：张清悄悄趱马出阵，被败卒指认，天山勇预伏一箭中喉。
- **驱民守城**：御弟"尽驱蓟州百姓上城守护"，火起后"各自逃归看家"。

## Worked Example
蓟州紧闭城门，吴用道："城中已有石秀、时迁在里面，如何担阁的长远？"教四面竖云梯炮架，再令凌振四下放炮，"攻击的紧，其城必破"。宋江早用本地人：公孙胜是蓟州人，杨雄做过节级，石秀时迁在那里住久；前日扮败残军马杂入城中。时迁躲宝严寺宝藏顶上，石秀送饭并去州衙放火，约定塔上起火为号。当晚时迁飞檐走壁先在宝塔点火，火光三十馀里，再到佛殿放火，城中鼎沸；石秀扒上州衙庭屋博风板点火，时迁又于山门放一把。御弟见无半个更次四五路火起，知有细作，开北门带老小奔幽州。宋江催兵卷杀入城夺了南门，先灭火、天明出榜安抚，功绩簿标写石秀、时迁功次。

## Key Takeaways
1. 陌生地理分兵，用"击首则尾应"的长蛇阵保证首尾相救。
2. 坚城不下时，提前埋本地人当内应，以火光为号。
3. 解围顺序：先退敌锋，再等外援，外援至即开门夹击。
4. 超级手段有天敌，王牌暴露后立刻换打法。
