# 第一回：张天师祈禳瘟疫 洪太尉误走妖魔

## Core Idea
一场以"志诚"为门票的使命，被只信肉眼、惯用权势的贵官办砸——全书一百八人的出场，源于一次把"封印"当可强行拆开的物件、而非需共同敬畏的契约的傲慢决策。识别门槛的性质，比拥有打开它的权力更重要。

## Frameworks Introduced
- **志诚心门槛**：求见天师靠"斋戒沐浴，更换布衣，休带从人，自背诏书，步行上山礼拜"。
  - When to use: 求见超验人物、需对方主动应允的使命。
  - How: 放弃身份排场，独自焚香叩请；大虫、大蛇即试探此心的关卡。
- **伏魔之殿的叠封制度**：每代天师"亲手便添一道封皮"，锁"用铜汁灌铸"，子孙"誓不敢开"。
  - When to use: 跨代隔离高后果风险。
  - How: 以封条＋祖训＋灾祸叙事累积威慑，使破坏成本高于好奇。
- **"遇洪而开"谶语**：石碑背面预凿开启者姓氏，使人为破坏被读作"天数"。
  - When to use: 解读灾祸的"合法性"来源。
  - How: 将人名嵌进封印，事后把偶然解释为必然。

## Key Concepts
- **洪太尉（洪信）**：奉旨祈禳的朝廷天使，以权势与理性傲慢误走妖魔。
- **嗣汉天师／虚靖天师**：居龙虎山顶茅庵，以倒骑黄牛、横吹铁笛的道童形象示人。
- **三千六百分罗天大醮**：仁宗为禳瘟疫而设、需天师亲临的道场。
- **伏魔之殿**：历代天师贴满封皮、铜汁灌锁的镇魔殿宇。
- **"遇洪而开"**：石碑背面四字谶语，点明开启者。
- **天罡星**：黑气散作金光而出世的一百八人。
- **度牒、刺配**：道士执业凭证与流放重刑，洪太尉用以胁迫真人。

## Mental Models
- 判断能否托付使命，看他如何应对"试探"，而非如何摆"门面"。
- 把"封印"看作需共同相信的契约，而非可撬的物理锁。
- 把"谶语"看作事后合法化工具——"遇洪而开"把人祸读成天意。

## Anti-patterns
- **以权势压服守门人**：以"追度牒、刺配远恶军州"威胁真人开门，把敬畏换成恐惧。
- **把试探当真危险而退缩**：遇虎蛇即折返，错过化为道童的天师。
- **以个人经验否定未知**："我读一鉴之书，何曾见锁魔之法"。

## Worked Example
游山至右廊后，洪太尉见"伏魔之殿"封皮重叠、铜锁沉重。真人告以历代天师亲手添封、"走了魔君非常利害"，三回五次禀说开不得。太尉却断定道士"假称锁镇魔王，煽惑百姓"，以参奏阻宣、追度牒刺配相胁，真人只得揭封锤锁推门。殿内黑不见物，火把照出石碑，碑后凿"遇洪而开"四字。太尉大喜，视为天数，命掘石龟、起青石板。真人苦禀不可，他那里肯听。石板一扛，地穴刮剌剌一声响，黑气滚起掀塌半个殿角，冲天散作百十道金光，望四面八方而去。众人发声喊奔出，太尉面色如土，真人叫苦不迭——"遇洪而开"把开封者写成天意执行人，也把一百八人放出了地穴。

## Key Takeaways
1. 守门人"三回五次"的劝阻是风险信号，应作为信息读取。
2. 不要用身份特权解决需要专业判断的问题——权势能撬锁，撬不开后果。
3. 真正的门槛往往考验态度而非能力，识别"试探"。
4. 警惕事先写好的"许可"：谶语式正当性是人祸的包装。
