# 第九十六回：卢俊义分兵歙州道 宋公明大战乌龙岭

## Core Idea
潜伏的最高形态不是藏匿，而是被敌方主动抬升为核心成员——柴进用对方最想听的天命叙事逐级通关、以婚姻绑定，把"细作"做成驸马；而战场另一端，主帅为夺回尸首亲自冒险，等于照敌方设好的诱饵行动。

## Frameworks Introduced
- **驸马潜伏（身份升级式间谍）**：柴进化名柯引，以"望天子气"说辞打动睦州四官，见方腊后称"夜观乾象，帝星明朗正照东吴，又见五色天子之气起自睦州"，封中书侍郎，再娶金芝公主成驸马。
  - When to use: 需长期潜伏到敌国最高决策层、获取军机时。
  - How: 以术数话术建立权威→逐级通关（守将→睦州四官→左丞相→方腊）→说对方想听的话→婚姻绑定获得内苑通行→持续投喂"罡星冲犯、二十八宿辅助"稳固信任。
- **火排水战（诱敌上滩）**：方腊"浙江四龙"预置五十连火排，四只快船诈败引阮小二上滩，火排顺风冲下、火炮齐发。
  - When to use: 敌方水军溯流攻寨时。
  - How: 弃船诱敌→火排顺风冲阵→挠钩搭船→火炮打头盔；识水者即时弃船逃生，被钩者难逃。
- **攀崖放火（猎户专长）**：解珍解宝扮猎户攀藤揽葛夜扒乌龙岭，欲放火惊敌弃关。
  - When to use: 山岭险峻、大路难攻，队中有猎户出身者时。
  - How: 穿虎皮套袄、跨快刀、提钢叉；高处遇挠钩须即砍断；拖叉刮藤出声则行踪暴露。
- **情绪化用兵的陷阱**：宋江不听吴用"贼兵将尸风化，诚恐有计"，连夜提兵三千夺尸，被石宝、邓元觉合围。
  - When to use: 折将后主帅被愤怒驱动时。
  - How: 反面教材——把"夺回尸首"当作战目标，就是按敌方设定行动。

## Key Concepts
- **浙江四龙**：玉爪龙成贵、锦鳞龙翟源、冲波龙乔正、戏珠龙谢福，原钱塘江梢公，方腊加封三品职事。
- **火排**：大松杉木穿成，堆草把、内藏硫黄焰硝引火之物，竹索编住，于滩头顺风冲下。
- **柯引／云壁**：柴进化名；燕青改名云壁，人称云奉尉。
- **金芝公主**：方腊之女，招赘柴进为驸马，封官主爵都尉。
- **金华太保／金华将军**：张顺死后封号，宋江于涌金门外建庙，后奉圣旨敕封，庙食杭州。
- **水陆道场七昼夜**：宋江在净慈寺为亡将设斋、判施斛食、超度沉冥。
- **患病寄留八员**：张横、穆弘、孔明、朱贵、杨林、白胜、穆春、朱富。
- **折了六将**：侯健、段景住、阮小二、孟康、解珍、解宝。

## Mental Models
- 当潜伏目标是最高决策层时，用对方最想听的叙事换信任，再用婚姻完成身份绑定。
- 把敌方水寨当作可预设的陷阱场，火排顺流专克溯流进攻的船队。
- 当主帅说"手足三停损了一停"时，把夺尸首视为敌方诱饵，情绪化用兵会正中下怀。
- 把后方赏赐与真实损失的差额，转化为对亡者的公开补偿仪式。

## Anti-patterns
- **不识水性的水军任务**：侯健、段景住落海淹死，与施恩、孔亮之死同类。
- **溯流攻寨不防火排**：阮小二自刎、孟康被炮打做肉泥。
- **攀崖拖叉刮藤出声**：解珍解宝"把搭膊拴住钢叉，拖在背后，刮得竹藤乱响"，被岭上发现。
- **主帅为夺尸首亲自冒险**：宋江拒吴用之谏，三千精兵夜进被围。

## Worked Example
柴进驸马潜伏。柴进、燕青自槜李亭别了宋江，渡海过越州至诸暨，到睦州界被关隘拦住。柴进自称中原秀士柯引，"知天文地理，善会阴阳，识得六甲风云"，"遥望江南有天子气数而来"。守将报知睦州右丞相祖士远等四官，皆被其言耸动，引他到清溪大内。左丞相娄敏中原是清溪县教学先生，见柴进高谈阔论，先自八分欢喜。次日方腊升殿，柴进奏"夜观乾象，帝星明朗正照东吴，又见一缕五色天子之气起自睦州，正应陛下龙凤之姿"，方腊大喜，敕赐锦墩命坐，加封中书侍郎。半月之间，方腊及内外官僚无一人不喜柴进。方腊又令娄敏中做媒，把金芝公主招赘柴进为驸马，燕青改名云壁。柴进由此出入宫殿、知内苑备细，方腊但有军情重事便宣他计议；他又以"罡星冲犯，尚有半年不安，直待并得宋江手下无了一员战将"等话稳固信任。柴进用一套对方想听的叙事，从秀士做到驸马，把潜伏推进到敌国核心。

## Key Takeaways
1. 长期潜伏要逐级通关，用对方最想听的叙事建立权威。
2. 婚姻绑定是获取核心区通行权最有效的手段。
3. 溯流攻水寨要先排查火排、挠钩等预设陷阱。
4. 主帅为夺尸首亲自冒险，等于按敌方诱饵行动。
5. 后方赏赐与战损脱节时，用仪式把赏赐转为对亡者的补偿。
