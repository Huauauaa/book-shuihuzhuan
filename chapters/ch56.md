# 第五十六回：吴用使时迁盗甲 汤隆赚徐宁上山

## Core Idea
破连环马靠的不是更强勇力，而是"专用工具＋唯一传人"：汤隆会打不会使、徐宁会使不肯来，吴用把取物变成环环相扣的诱捕——盗甲、留空匣、假认匣、路上作证、冒名抢劫，直到断尽回乡之路，徐宁才"只得"坐上交椅。

## Frameworks Introduced
- **专用克制的寻找**：破成系统的敌阵，先定位"工具＋传人"两个缺口。
  - When to use: 常规战法对连锁阵无效时。
  - How: 汤隆指出"先朝曾用这连环甲马取胜，破阵须用钩镰枪"；自家"祖传已有画样"，会打不会使；会使的只有姑舅哥哥、金枪班教师徐宁，"祖传习学，不教外人，马上步行都有法则"。
- **时间窗潜入（时迁盗甲）**：踩点、藏身、乘隙、脱身，全卡在守卫空档。
  - When to use: 要在特定时段取物且不能惊动人家时。
  - How: 白日问街坊得知徐宁"晚方归，五更便去内里随班"，看清前后门与戗柱；夜里夹柏树坐候，从后门扒墙入，伏博风板观徐宁围炉、梁上皮匣；四更趁丫嬛开后门潜入厨桌下，待徐宁出门便上楼伏梁；吹灯解匣，以"老鼠厮打"遮响，趁随班人四更开锁"从人队里趁闹出去"。
- **空匣诱敌的连环套**：留空匣作饵，比留真物更能驱动对方主动追来。
  - When to use: 要让一个人"自愿"离家、又不能强绑时。
  - How: 时迁把空皮匣"明明的拴在担子上"，凡有白粉圈儿的店便买酒肉、把匣放"在他眼睛头"；汤隆假称四十里外见"鲜眼黑瘦汉子"挑此匣，并说出匣上细节取信；古庙只见空匣；时迁装"闪肭了腿"编泰安财主许一万贯之说；乐和扮"泰安李荣"搭车下蒙汗药。

## Key Concepts
- **钩镰枪**：破连环甲的专用兵器；汤隆祖传画样、雷横监督打造，徐宁祖传习学"天下独步"。
- **雁翎锁子甲／赛唐猊**：徐宁祖传四代之宝，"又轻又稳，刀剑箭矢急不能透"；红羊皮匣盛、挂卧房梁上。
- **鼓上蚤时迁**：盗甲执行者，学鼠叫、吹灯、伏梁，趁四更随班人出门混出。
- **铁叫子乐和**：扮"泰安李荣"搭车，以蒙汗药擒徐宁。

## Mental Models
- 把"连环马"看作锁在一起的系统：破它要专用工具加唯一传人。
- 把"盗甲"看作时间窗作业：动作卡在四更到五更之间。
- 把"空匣"看作诱饵：能被"看见"的空物比藏起来的真物更驱动人。

## Anti-patterns
- **半夜贸然下手**：时迁"倘若闹将起来，明日出不得城"，坚持捱到五更随班人开门才动手。
- **失主声张**：徐宁恐"枉惹他人耻笑"，娘子嘱"且不要打草惊蛇"；汤隆才敢登门假认。

## Worked Example
时迁到东京访徐宁家，问街坊得知徐宁"晚方归来，五更便去内里随班"。他夹住大柏树坐候；见徐宁归家、班里人关门上锁，从后门扒墙进院，伏在博风板边，张见徐宁与娘子围炉向火、梁上拴着大皮匣。二更后徐宁上床，说明日五更随班，时迁"捱到五更里下手"，吹灭碗灯。四更徐宁唤丫嬛烧汤，时迁潜入厨房贴身厨桌下；待徐宁背金枪出门便上楼伏梁，再吹灯解匣。徐宁娘子听得响动，时迁"做老鼠叫""学老鼠厮打"遮过去，开楼门背匣下胡梯，趁四更开锁"从人队里趁闹出去"。奔出城到客店取行李，行四十里遇戴宗——戴宗把真甲拴身上作神行法先投山寨，时迁却把空皮匣明拴担上，专往白粉圈儿店打尖。另一路汤隆登门假认此匣、引徐宁连夜追赶，终至古庙树下"寻见"空匣，再生出泰安财主一段谎话；乐和扮李荣搭车，过山时以下蒙汗药把徐宁送到金沙滩。

## Key Takeaways
1. 破系统要找"专用工具＋唯一传人"，不是加更多勇力。
2. 潜入取物先摸时间窗，把动作卡在守卫空档。
3. 诱饵要能被"看见"：空匣比藏起来的真物更驱动对方追来。
4. 赚人是断退路工程：盗甲、赚上路、取家眷、冒名抢劫，环环相扣。
