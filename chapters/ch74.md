# 第七十四回：燕青智扑擎天柱 李逵寿张乔坐衙

## Core Idea
燕青以"有力使力，无力斗智"破解身长一丈、千百斤气力的任原：不硬碰，逼其转身、借其体重旋下献台，一扑"鹁鸽旋"取胜。三条约定管住偷下山的李逵守住大半程；任原一倒、徒弟抢利物，李逵仍拔杉木打人——胜者收势、失控者惹祸。

## Frameworks Introduced
- **有力使力，无力斗智**：不与巨力者正面对抗，让体积与转身不便成为弱点。
  - When to use: 对手力量远超自己时。
  - How: 燕青"不动弹，只瞅他下三面"；任原虚出左脚，燕青叫"不要来"，"去左胁下穿将过去"；任原转身来拿，燕青"虚跃一跃，又在右胁下钻过去"；"大汉转身终是不便，三换换得脚步乱了"；燕青托起任原"借力便旋，四五旋旋到献台边，叫一声：'下去！'"
- **示弱藏锋**：用卑微身份掩盖意图，待对手轻敌时出手。
  - When to use: 需接近强敌而不打草惊蛇时。
  - How: 燕青扮山东货郎儿，衲袄包花绣、腰插串鼓儿、挑杂货担，唱货郎太平歌；见任原粉牌"拳打南山猛虎，脚踢北海苍龙"，扯匾担打碎——劈牌放对；任原"今年那个合死的"叫阵，燕青低头急出店门。
- **三约束伴**：给惹事同伴划具体行为边界。
  - When to use: 不可控者随行、场合敏感时。
  - How: 路上"前后各自走，入店门便不要出来"；客店"推病，把被包了头脸，假做打齁睡"；庙上"挨稠人看争交，不要大惊小怪"；李逵要带板斧，"被人看破，误了大事"。
- **以招安代征伐**：以"民心既伏、辽兵犯境"改剿为抚。
  - When to use: 兵力被外敌牵制时。
  - How: 崔靖奏"替天行道，此是曜民之术。民心既伏，不可加兵。即目辽兵犯境……若要起兵征伐，深为不便"；建议"降丹诏、颁御酒，差大臣招安来降，假此以敌辽兵，公私两便"。

## Key Concepts
- **献台 / 部署**：献台即擂台，部署持竹批主持，读社条"不许暗算"
- **擎天柱任原**：太原府扑手，身长一丈、千百斤气力，两年在岱岳夺头筹。
- **鹁鸽旋**：燕青托起任原借力旋下献台的那一扑。
- **劈牌放对**：燕青扯匾担打碎任原粉牌，公开应战。
- **山东货郎儿**：燕青伪装——衲袄包花绣、串鼓儿、杂货担。
- **乔坐衙**：李逵在寿张县穿知县公服、排衙、枷号原告。

## Mental Models
- 力量绝对占优时用"有力使力，无力斗智"：逼他转身，让体积成累赘。
- 把"示弱"看作武器：扮货郎、包花绣、推病藏人，换轻敌一瞬。
- 把"约束惹事同伴"看作可执行约定，而非空口劝告。

## Anti-patterns
- **以貌取人**：知州"金刚般大汉，你敢近他不得"，店小二"任原吞得你在肚里"。
- **胜后不收势**：任原徒弟抢利物，李逵拔杉木打人、揭石板打碎任原头。
- **私走下山**：李逵"不曾对哥哥说知，偷走下山"，宋江骂"该死的罪过"。

## Worked Example
三月二十八，岱岳庙献台前，任原夸口"东至日出，西至日没……敢有和我争利物的么"。燕青扮山东货郎飞抢上献台，自称"山东张货郎"，"我是保人，死了要谁偿命"。知州劝他分利物还乡，燕青只说"只要攧翻他，教众人取笑"。开局任原步步逼来，燕青不动，只瞅下三面；任原虚出左脚，燕青叫"不要来"，从他左胁下穿过；任原转身来拿，燕青虚跃一跃又从右胁下钻过。"大汉转身终是不便，三换换得脚步乱了。"燕青抢入，右手扭住、左手插入交档、肩胛顶胸脯，托起任原借力旋四五旋到台边，一声"下去"，头下脚上撺下台——名唤"鹁鸽旋"，数万香官喝采。随即任原徒弟抢利物，李逵拔杉木打人、揭石板打碎任原头，卢俊义引一千人杀开庙门接应，方收队回山。

## Key Takeaways
1. 以弱胜强不靠蛮力：逼对手转身，借其体重旋转，让优势变负担。
2. 接近强敌前先隐藏意图——卑微装束、假装病弱、低头退避。
3. 对惹事同行者立具体约定（分开走、装病、不乱叫），并预埋接应。
4. 赢下后要能收势；纵容同伴追打会把公平较量变成官府围剿把柄。
