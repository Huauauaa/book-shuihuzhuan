# 第五十五回：高太尉大兴三路兵 呼延灼摆布连环马

## Core Idea
单个猛将不可怕，可怕的是把猛将编成系统：呼延灼用铁环把三十匹马锁成一队，梁山第一次正面战败。破局不在硬拼，而在先收服降将、再找破"连锁"的专用军器——汤隆的钩镰枪由此登场。

## Frameworks Introduced
- **三路兵的动员闭环**：保将、调兵、领甲仗、拨战马、立军状，一环不缺。
  - When to use: 组织一次成建制远征时。
  - How: 呼延灼保韩滔（百胜将军、枣木槊）为正先锋、彭玘（天目将军、三尖两刃刀）为副先锋；高太尉下牒文星夜调取；三路军马五千、连步军一万；甲仗库任拣铁甲三千副、熟皮马甲五千副、火炮铁炮五百余架；另拨战马三千匹；三将"都与了必胜军状"。
- **车轮战消耗（纺车般转作后军）**：先以力敌，后用智擒，不求一战决胜。
  - When to use: 敌将武艺精熟、"人不可近"时。
  - How: 宋江定五阵——秦明、林冲、花荣、一丈青、孙立，"一队队战罢，如纺车般转作后军"；一丈青用红锦套索（二十四个金钩）拖彭玘下马，孙立与呼延灼钢鞭对钢鞭斗三十余合不分胜败。
- **连环甲马**：把个体优势锁成不可拆的系统优势。
  - When to use: 平原开阔地对抗步骑混杂的敌军时。
  - How: 呼延灼"每三十匹一连，却把铁环连锁……三千连环马分作一百队锁定，五千步军在后策应"；"每一队三十匹马一齐跑发，不容你不向前走"；马带马甲只露四蹄、人披铁铠只露眼睛，宋江阵上箭射不进、近前不得。

## Key Concepts
- **呼延灼／双鞭**：呼延赞嫡派子孙、汝宁郡都统制，使两条水磨八棱钢鞭，骑御赐踢雪乌骓。
- **百胜将韩滔**：陈州团练使、武举出身，使枣木槊，正先锋。
- **天目将彭玘**：颍州团练使、将门之子，使三尖两刃刀；被一丈青套索拖下马，留寨做头领。
- **连环甲马**：每三十匹一连、铁环连锁，三千匹分作一百队，马带马甲、人披铁铠。
- **轰天雷凌振**：甲仗库副使炮手，善造火炮可及十四五里，分风火炮、金轮炮、子母炮。
- **金钱豹子汤隆**：本回末献计——"除是得这般军器和我一个哥哥，可以破得连环甲马"。

## Mental Models
- 把"必胜军状"看作动员的承诺机制：立状领赏，把风险绑回将领身上。
- 把"车轮战"看作消耗强敌的接力：五阵轮替，再以套索取将。
- 把"连环马"看作系统优势：破的是"连锁"结构，不是某一匹马。

## Anti-patterns
- **骂阵轻敌**：韩滔"把你水泊填平、梁山踏碎"，转瞬"力怯，只待要走"；彭玘也被拖下马。
- **炮手孤军深入**：凌振追到芦苇滩、夺船到波心被拔楔扳翻，"轰天雷"反被生擒。

## Worked Example
宋江分五队在前、两路伏兵左右，令秦明搦战。呼延灼阵里只呐喊不交锋，一千步军擂鼓发喊。宋江疑惑，纵马到花荣队里窥望。猛听连珠炮响，一千步军分作两下，三队连环马直冲：两边弓箭乱射，中间长枪，每一队三十匹马一齐跑发，"不容你不向前走"，漫山遍野横冲直撞。前面五队乱窜，后面大队拦当不住，各自逃生；宋江飞马慌走。一队连环马追来，伏兵李逵、杨林从芦苇中杀出救得宋江；逃到水边，李俊、张横、张顺、三阮六人摆船接应，船上傍牌遮护箭不能伤，棹到鸭嘴滩上岸。整点折其大半，却喜众头领都全，只折些马匹。宋江抚慰，计点中箭者六人：林冲、雷横、李逵、石秀、孙新、黄信。呼延灼大获全胜，生擒五百余人、夺马三百余匹，差人报捷；徽宗赐御酒锦袍赏军。呼延灼又求"轰天雷"凌振攻贼巢——后仍被水军诱擒。

## Key Takeaways
1. 成建制远征要形成闭环：保将、调兵、领甲仗、拨战马、立军状。
2. 遇强敌不硬拼：用车轮战轮番消耗，再以套索等专门手段取将。
3. 面对"系统优势"（连环马），破的是连锁结构，不是单个单位。
4. 收编降将最省成本：解缚、陪话、保家属，换来"捐躯保奏"。
