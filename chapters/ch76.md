# 第七十六回：吴加亮布四斗五方旗 宋公明排九宫八卦阵

## Core Idea
梁山不急交战，先用阵势展示完成心理战：哨骑三挑不战、伏兵倒提蛮牌诈败，把童贯引出山嘴到平川旷野，再摆出明分八卦、暗合九宫的九宫八卦阵，令十万官军主帅"魂飞魄散"。董平、索超随后争抢"捉童贯"头功，也为下回埋伏笔——阵是威慑，也是纪律的试金石。

## Frameworks Introduced
- **诱敌出山**：哨骑挑衅＋伏兵诈败，把坚壁的敌军引出有利地形。
  - When to use: 敌方依险不出、己方需开阔战场时。
  - How: 张清带龚旺、丁得孙"直哨到童贯军前，只隔百十步，勒马便回"，连哨三遭；左右劝"锦袋中都是石子，发不放空，不可追赶"；李逵、樊瑞、项充、李衮五百步军"都倒提着蛮牌，踅过山脚便走"，童贯赶出山嘴到平川旷野。
- **九宫八卦阵**：把全军编码进方位—五行—卦象—将职的坐标系统。
  - When to use: 要以阵法威慑并分割敌军时。
  - How: 正南丙丁火朱雀红旗秦明、东壁甲乙木青龙青旗关胜、西壁庚辛金白虎白旗林冲、北方壬癸水玄武皂旗呼延灼；东南巽卦董平、西南坤卦索超、东北艮卦史进、西北乾卦杨志；中央戊己土杏黄旗，郁保四守"替天行道"旗，凌振炮架、焦挺守帅旗，戴宗执令旗、燕青背弩护中军，宋江坐照夜玉狮子马监战。
- **先声夺人**：不急交战，先展示完整阵势使对方胆落。
  - When to use: 敌军新至、士气正盛时。
  - How: 童贯"定睛看了梁山泊兵马……惊得魂飞魄散，心胆俱落，不住声道：'可知但来此间收捕的官军便大败而回，原来如此利害！'"；看了半晌才"催战的锣鼓不住声发擂"。

## Key Concepts
- **童贯**：枢密使、统军大元帅，统十万大军。
- **四门斗底阵**：童贯在将台上所摆，与九宫八卦阵对峙。
- **五方旗色**：南红丙丁火、东青甲乙木、西白庚辛金、北皂壬癸水、中央杏黄戊己土。
- **八卦门将**：巽卦董平、坤卦索超、艮卦史进、乾卦杨志。
- **替天行道杏黄旗**：中央所立，郁保四守旗。
- **霹雳火秦明**：二十馀合卖破绽，一棍把陈翥"连盔带顶，正中天灵"打死。

## Mental Models
- 敌军依险坚守时用"哨骑挑衅＋伏兵诈败"，拖到你的战场再决战。
- 把阵势看作信息系统：旗色、五行、卦象、将职共同传递"不可敌"。
- 拒绝忠言的主帅必然轻敌：童贯骂张叔夜"懦弱"，关上纠错通道。

## Anti-patterns
- **怒气长驱**：童贯反骂张叔夜"畏刀避剑，贪生怕死，误了国家大事"。
- **追赶石子将**：左右提醒"石子发不放空，不可追赶"。
- **阵前逞个人勇**：陈翥被秦明一棍打死；董平、索超争抢"捉童贯"带乱阵型。

## Worked Example
童贯在攒木将台上望见山后炮响，梁山军马占住中央：正南红旗朱雀秦明、东壁青旗青龙关胜、西壁白旗白虎林冲、北面皂旗玄武呼延灼，东南巽卦董平、西南坤卦索超、东北艮卦史进、西北乾卦杨志分守四门。中央杏黄旗间六十四面长脚旗，郁保四守"替天行道"旗，凌振炮架在后，焦挺守帅字旗；戴宗执令旗、燕青背弩护中军，公孙胜吴用分左右，宋江坐照夜玉狮子马监战。童贯"惊得魂飞魄散，心胆俱落"，叹"可知但来此间收捕的官军便大败而回，原来如此利害"。待宋江军中锣鼓催战，郑州都监陈翥出阵叫骂，秦明舞狼牙混棍迎战，斗二十馀合卖破绽，一棍"连盔带顶，正中天灵"，陈翥翻身死。董平、索超见秦明得头功，各叫"不就这里捉了童贯，更待何时"，直撞过阵来——威慑转为总攻。

## Key Takeaways
1. 引敌出险不要硬攻：哨骑挑衅、伏兵诈败，把对方拖到你的战场。
2. 布阵不只是站位，而是编码系统：旗色、五行、卦象、将职一起传递信息。
3. 威慑先于交战：让对方主帅先怯，比先斩一将更有战略价值。
4. 阵法再严也挡不住部将抢功冲动——董平、索超擅自冲阵是下回入口。
