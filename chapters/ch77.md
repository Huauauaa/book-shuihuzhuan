# 第七十七回：梁山泊十面埋伏 宋公明两赢童贯

## Core Idea
吴用的十面埋伏不是一次合围，而是分层漏斗：每层吃掉一部分、放残兵继续跑，让童贯始终在"刚脱险又遇伏"的循环里，长蛇阵被逐段搅碎。宋江在胜势中"不肯尽情追杀"、亲解酆美之缚放归——打的是"两赢"，谋的是招安。

## Frameworks Introduced
- **十面埋伏**：多梯队按地形逐段截杀，而非一次合围。
  - When to use: 敌军数量大、需分段歼灭并故意放主帅逃生传信时。
  - How: 张顺水战困杀五百军汉；朱仝雷横黄旗军卖破绽诱追；秦明关胜红旗青旗、呼延灼林冲黑白二旗；鲁智深武松步军、解珍解宝钢叉"搅碎长蛇大阵"；董平索超、杨志史进；卢俊义活捉酆美；李逵鲍旭项充李衮；张清一石子打中周信鼻凹——三停折了二停。
- **不尽情追杀（留人传信）**：故意放主帅回去传播恐惧，比就地歼灭更利于招安。
  - When to use: 目标是招安而非消灭敌人时。
  - How: 吴用"且未可尽情追杀，略报个信与他"；宋江"素怀归顺之心，不肯尽情追杀……差戴宗传令，收拾各路军马都回山寨请功"；卢俊义活捉酆美，宋江"自解其缚，请入堂内上坐"，留两日放归，托他"回朝善言解救"。
- **孤身诱敌（张顺蓑衣钓鱼）**：单人异装引敌注意并大量消耗其兵力。
  - When to use: 要挫敌锐气、消耗其有生力量时。
  - How: 张顺"头戴青箬笠，身披绿蓑衣，独自钓鱼"；三百硬弓乱箭射中蓑衣箬笠"都落水"——箬笠内衬铜、蓑衣"熟铜打就，如龟壳相似"；五百军汉赴水被棹竿打落、腰刀戳沉，"血水滚将起来"。

## Key Concepts
- **十面埋伏**：吴用布置的分层截杀，"杀得童贯胆寒心碎，梦里也怕"。
- **长蛇阵**：酆美、毕胜所摆"击首则尾应"之阵，被逐段搅碎。
- **浪里白跳张顺**：披熟铜蓑衣钓鱼诱敌，水中腰刀戳杀军汉。
- **朱仝 / 雷横**：黄旗五千人，斗二十合卖破绽诱童贯追过山脚。
- **没羽箭张清**：三百骑铜铃面具，一石子打中周信鼻凹。
- **玉麒麟卢俊义**：火把光中拦路，活捉酆美——"马步军中惟第一"。

## Mental Models
- 把十面埋伏看作分层漏斗：每层只吃一部分，主帅始终在"刚脱险又遇伏"里。
- 把"不追尽"看作战略选择：放主帅回去传播恐惧，更利于招安。
- 把"教条阵法"看作脆弱系统：多段切入就让"首尾相应"失联。

## Anti-patterns
- **主帅亲临险地**：童贯"事已到这里，岂可退军"，酆美谏"不可亲临险地"不听。
- **阵法教条**：长蛇阵在芦苇地形被逐段搅碎。
- **轻看水中对手**：五百军汉下水捉渔人，"若有回来的，一刀两段"，全沉水底。

## Worked Example
童贯养锐三日摆长蛇阵再进，到水泊边不见一军，只见对岸渔人披蓑戴笠独自钓鱼。三百硬弓乱箭射去，中箬笠蓑衣皆"当地一声落水"——箬笠内衬铜、蓑衣熟铜如龟壳。五百军汉赴水来捉，被张顺棹竿打落、腰刀戳沉，血水滚起。山顶黄旗磨动，朱仝、雷横引黄旗军杀来，斗二十合卖破绽便走；童贯追过山脚，画角齐鸣，杏黄旗闪出"替天行道"，宋江与吴用立马山上。童贯怒欲上山，酆美谏"不可亲临险地"不听。四下伏兵齐起：秦明关胜红旗青旗、呼延灼林冲黑白二旗、鲁智深武松步军、解珍解宝钢叉"搅碎长蛇大阵"、董平索超、杨志史进层层截杀。童贯四更杀出重围，又被卢俊义火把下拦住，酆美被活捉。宋江却传令收军，亲解酆美之缚，留两日放归——打的是两赢，谋的是招安。

## Key Takeaways
1. 围歼大股敌军不要一次合围：分层截杀、放残兵前跑，持续制造压力。
2. 若目标是招安就放主帅回去传播恐惧，并礼送俘虏带回"归顺之心"。
3. 阵法是系统，依赖联络；多段切入就能让长蛇首尾失联。
4. 主帅"不可亲临险地"的忠告要听——童贯两次拒绝，两次送进更深埋伏。
