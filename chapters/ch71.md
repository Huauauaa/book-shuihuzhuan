# 第七十一回：忠义堂石碣受天文 梁山泊英雄排座次

## Core Idea
宋江借罗天大醮掘石碣、译天书，把一百八人座次包装成天意，众人"各守其位，各休争执"；又歃血盟誓把义气变成组织契约。但重阳《满江红》一句"望天王降诏早招安"引爆武松、李逵、鲁智深反对：天意解决"谁坐哪里"，解决不了"往哪里去"。

## Frameworks Introduced
- **石碣受天文（以天意定序）**：借神迹为排序赋予不可争辩的合法性。
  - When to use: 成员资历功劳难以比较时。
  - How: 大醮七昼夜→天门开、火块钻入正南地下→掘石碣→何玄通辨蝌蚪文、萧让誊写→天罡三十六、地煞七十二→"各守其位，不可逆了天言"。
- **分职定责（执事清单）**：排名同时把每人编入岗位，名分与职司一起落地。
  - When to use: 人数过百、要把"聚义"转为组织时。
  - How: 总兵都头领宋江卢俊义、军师吴用公孙胜、钱粮柴进李应；五虎将、八骠骑、小彪将十六、步军头领十、水军八、四店八、总探戴宗、监造十六；山顶杏黄旗"替天行道"，堂柱金书"常怀贞烈常忠义，不爱资财不扰民"。
- **歃血誓盟（共同契约）**：公开仪式把效忠转为组织约束。
  - When to use: 需把义气变成可追责的承诺时。
  - How: 拈香跪堂，宋江誓"死生相托，吉凶相救，患难相扶，一同保国安民"，违者"天地行诛，神人共戮"。
- **词曲试探路线**：用文艺投影主帅意图，看谁先反对再分级处置。
  - When to use: 欲推重大转向而不愿摊牌时。
  - How: 乐和唱至"望天王降诏早招安"→武松"冷了弟兄们的心"、李逵踢桌"招甚鸟安"→宋江喝令斩→众人跪求改监下→次日"寄下你项上一刀"。

## Key Concepts
- **罗天大醮**：七昼夜道场，公孙胜主行，报天地、荐晁盖、祈赦罪。
- **石碣天书**：龙章凤篆蝌蚪文，正面三十六天罡、背面七十二地煞。
- **替天行道 / 忠义双全**：石碣两侧四字；山顶杏黄旗书"替天行道"。
- **马军五虎将**：关胜、林冲、秦明、呼延灼、董平。
- **八骠骑兼先锋使**：花荣、徐宁、杨志、索超、张清、朱仝、史进、穆弘。
- **菊花之会 / 《满江红》**：重阳筵上宋江醉词，末句"望天王降诏早招安，心方足"。

## Mental Models
- 组织需要排序合法性时，用"天意"叙事替代论功——争位即"逆了天言"。
- 把"排座次"看作装进职能网格：先定岗位，再定名次。
- 把"喝令斩李逵"看作仪式性惩戒：斩→求情→寄下刀，立威而不失情。

## Anti-patterns
- **以功争位**：宋江明言"各守其位，各休争执，不可逆了天言"。
- **酒后直斥路线**：李逵踢桌"招甚鸟安"，虽免死仍被监下。
- **一概否定招安**：鲁智深断言"招安不济事"，席终"终不畅怀"。

## Worked Example
重阳筵上，忠义堂遍插菊花，马麟品箫、乐和唱曲、燕青弹筝。宋江大醉作《满江红》，乐和唱至"望天王降诏早招安，心方足"，武松叫"冷了弟兄们的心"，李逵睁圆怪眼"招甚鸟安"，一脚踢碎桌子。宋江大喝"推去斩讫报来"，众人跪求，改"推去监下"。当夜宋江酒醒发悲，忆江州反诗旧事，说李逵"情分最重，如骨肉一般"；鲁智深斥"满朝文武俱是奸邪……招安不济事"，欲拜辞散去。次日李逵请罪，宋江"寄下你项上一刀"——一次试探，把招安之争从暗处搬到明处。

## Key Takeaways
1. 排序借"天书石碣"外化为不可争辩的既成事实，不让人自报功劳。
2. 排座次与分职司同时完成，名分岗位一起给。
3. 歃血盟誓把义气升级为可追责契约，违誓者"天地行诛"。
4. 重大路线先用词曲试探，看谁第一个反对，再分级处置。
