# 第八十九回：宋公明破阵成功 宿太尉颁恩降诏

## Core Idea
破阵是把玄女法翻译成可执行配置——五色军马、五行主将、二十四部雷车、初更时序；胜利后却要交给朝廷程序：辽国以贿赂买通省院，宋江拒绝"以贿赂相许"却仍认"取自上裁"，结果叹一句"功勋至此又成虚度"。

## Frameworks Introduced
- **把法翻译成配置**：玄女给原理，宋江落成颜色、主将、人数、器物。
  - When to use: 拿到抽象的方法论时。
  - How: 黄袍董平战水星、白袍林冲战木星、红袍秦明战金星、黑袍呼延灼战火星、青袍关胜战土星；另设绣旗花袍打太阳、素袍银甲打太阴、卢俊义等直擒国主、李逵等护雷车；造二十四部雷车。
- **夜袭时序**：先清外围、统一信号、同时发难。
  - When to use: 对方阵势完整、白日强攻无效时。
  - How: "断芦为笛，衔于口中，唿哨为号"；黄昏先分四路赶杀哨路绕阵脚北去，只留黄袍军摆阵前；初更连珠炮响五路齐入；公孙胜敕起五雷，雷车火起、霹雳交加。
- **多层配合斩主帅**：敌帅披重甲时，用刀箭石子叠加破坏。
  - When to use: 主帅重甲护身、难以一击毙命时。
  - How: 关胜正面缠斗；花荣箭中护心镜与凤翅金冠；张清石子打得兀颜光"扑在马上"；关胜青龙刀"连腰截骨带头砍着"，张清再复一枪。
- **拒贿而守程序**：当场拒绝贿赂，但裁决权在上层，仍按程序办。
  - When to use: 对方用非正当手段影响你，而决定权不在你。
  - How: 褚坚许金帛，宋江斥"汝今以贿赂相许，觑宋江为何等之人！再勿复言"；赵枢密"须取自上裁，我未敢擅便"，宋江按兵不动，差柴进萧让赍奏赴京。

## Key Concepts
- **雷车二十四部**：按二十四气，下装油柴、上安火炮，李逵等引五百牌手护送。
- **五色军马 / 五行**：戊己土黄袍董平、庚辛金白袍林冲、丙丁火红袍秦明、壬癸水黑袍呼延灼、甲乙木青袍关胜。
- **兀颜光三重铠甲**：连环镔铁铠、海兽皮甲、锁子黄金甲，关胜一刀"只透的两层"。
- **一丈青擒天寿公主**：抢入怀内劈胸揪住，王矮虎赶上活捉。
- **褚坚**：辽国右丞相太师，许宋江金帛被斥，遍贿蔡京童贯高俅杨戬。

## Mental Models
- 抽象规则要落成参数（颜色、主将、人数、器物、时辰）才能执行。
- 夜袭先清外围、统一信号、同时发难，比逐路添兵更能放大混乱。
- 拒贿不等于拒程序：把裁决交给"上裁"，哪怕上层可能被潜规则改写。

## Anti-patterns
- **以贿赂买结果**：褚坚遍贿省院，蔡京等"极力保奏"，战场胜利被朝廷潜规则抵消。
- **越权许和**：宋江既不收贿也不自许退兵，坚持"取自上裁"。
- **主帅脱离亲兵**：兀颜光"身畔没了羽翼"仍北走，被花荣关胜张清接力追杀。

## Worked Example
宋江把玄女法落成实配：黄袍董平战水星、白袍林冲战木星、红袍秦明战金星、黑袍呼延灼战火星、青袍关胜战土星，另设太阳太阴擒王护车四枝。黄昏朔风彤云、未晚先黑，教军士断芦为笛衔口唿哨为号，先分四路赶杀辽军哨路绕阵脚北去，只留黄袍军在阵前。初更连珠炮响五路同时杀入，公孙胜敕起五雷，南风大作走石飞沙，李逵等引五百牌手护送雷车推入中军，火起霹雳交加。兀颜光急上马时雷车已到，关胜杀至帐前；花荣两箭射中护心镜与凤翅金冠，张清石子打得他扑在马上，关胜青龙刀"连腰截骨带头砍着"攧下马，张清再复一枪。鲁智深杀入太阳阵，武松断耶律得重马头；一丈青打入太阴阵，王矮虎活捉天寿公主；卢俊义砍翻帅字旗，直杀到四更，辽兵二十余万不留一个。

## Key Takeaways
1. 抽象规则要落成参数才能执行：颜色、主将、人数、器物、时辰。
2. 夜袭先清外围、统一信号、同时发难。
3. 重甲强敌靠多手段叠加（刀箭石）逐层破坏。
4. 拒贿不等于拒程序：把裁决交给"上裁"。
