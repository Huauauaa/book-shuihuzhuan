# 第八十一回：燕青月夜遇道君 戴宗定计赚萧让

## Core Idea
中间人许诺不兑现，坐等只会"空劳神力"还搭上质当：燕青用李师师这条"枕头上关节"把梁山实情直送天听、赚到御笔赦书，又与戴宗下宿太尉书另立正式渠道，最后贿虞候、四更漾索把萧让乐和赚出高墙——破封锁靠绕道与接应。

## Frameworks Introduced
- **观人断言**：吴用观高俅"蜂目蛇形，转面无恩"，断其回京必推病不出、软监萧让乐和。
  - When to use: 对方许诺回转却久无消息时。
  - How: 先按品性预判反覆，选"乖觉的人，多将金宝，钻刺关节，把衷情达知今上"。
- **双轨钻刺**：私路直达决策者，另立可信的正式渠道。
  - When to use: 正式奏请被中间人垄断时。
  - How: 燕青入肩李师师、唱曲陈情求御笔赦书；同时持闻焕章尺书当街跪呈宿元景，以华州旧识加金珠固其心。
- **以艺为媒、以亲为界**：用才艺讨中间人欢心，再用认亲设誓压住邪心。
  - When to use: 须借风尘中人接近权力时。
  - How: 燕青吹箫拨阮唱曲使李师师"倒有心看上他"，随即问年庚拜为姐姐，"拜住那妇人一点邪心"，设誓"若为酒色而忘其本，死于万剑之下"。
- **赚人出禁**：贿看守、约暗号、借柳索接出。
  - When to use: 人被高墙软禁、梯凳尽藏。
  - How: 戴宗以一锭大银贿小虞候换一见；约"咳嗽为号""四更为期"，漾两索借墙边大柳绞缚，墙外各扯一索让二人盘下；府后河空船接应。

## Key Concepts
- **蜂目蛇形**：吴用相高俅之相，断其转面无恩。
- **钻刺关节**：以金宝打通关节，越中间人把下情达"今上"。
- **入肩**：燕青旧年闹东京即在李师师家入肩，此回重入求"枕头上关节最快"。
- **道君皇帝**：徽宗私行，扮白衣秀士从地道到李师师家。
- **御笔赦书**：无御宝，李师师称"御笔强似玉宝天符"，写"特赦燕青本身一应无罪"。
- **宿太尉宿元景**：天子近侍，与宋江华州有一面之识，正应"遇宿重重喜"。
- **闻参谋尺书**：闻焕章自陈"三番败绩"，求宿太尉"不惜齿牙"。
- **赚萧让**：咳嗽为号、四更漾索、柳树绞缚、空船遁走。

## Mental Models
- 中间人垄断信息时用双轨：直达决策者的私路＋另立的正式渠道。
- 借诱惑性中间人接近权力，才艺是门票，认亲设誓是边界。
- 软禁是可拆系统：看守用银买、高墙用索越、梯藏用柳替。

## Anti-patterns
- **轻信许诺坐等**：高俅设大誓许保奏，吴用断其必"推病不出"；坐等则"空劳神力"还陷二人。
- **酒色误事**：李师师三回五次撩拨，燕青若"心猿意马"便坏大事，故设誓压住。
- **走明路自投**：各门盘诘严，燕青以假公文称"开封府勾当"才混过。

## Worked Example
燕青先以金珠拜李妈妈、李师师，认作姐姐与干娘，把妇人邪心"拜住"。当夜道君皇帝扮白衣秀士从地道入李师师家，燕青被唤进房，先吹箫拨阮，再唱《渔家傲》；改唱《减字木兰花》——"听哀告……有朝须把大恩人报"。天子失惊追问，燕青大哭，称被梁山掳去三年、今逃回京师不敢上街。李师师撒娇求亲书，天子说无御宝，她答"御笔强似玉宝天符"，天子写下"特赦燕青本身一应无罪，诸司不许拿问"。燕青叩头受命后，又把两番招安被读破句读、抵换御酒，童贯两阵片甲不回、高俅三阵折兵被擒却谎称患病等事和盘托出。天子叹"寡人怎知此事"。赦书到手，实情也绕过高俅直达天听。

## Key Takeaways
1. 中间人许诺不兑现，先判其性再铺旁路，别催问。
2. 直达决策者的捷径常在正式渠道之外。
3. 借力诱惑性中间人，先把边界立牢（认亲、设誓）。
4. 软禁可解：买通看守、约暗号、借柳树与河船接人。
5. 面陈带两样：可留存的凭证＋对方不知道的实情。
