# 第九十一回：张顺夜伏金山寺 宋江智取润州城

## Core Idea
攻坚城的关键不在强渡，而在先取"真凭据"：一名水军好汉潜水夺船、审出敌方密约，再用缴获的官诰号衣把伏兵包装成对方的押粮队伍，使敌人在验证环节因接旨而暂停搜查，城门遂被里外夹攻打开。

## Frameworks Introduced
- **赴水探敌（潜水夺船审俘）**：张顺把衣服裹两大银顶在头上、腰插尖刀，从瓜洲下水直赴金山寺；见小船"来得跷蹊"又钻入水底，削倒摇橹二人，逼问干人吴成，尽得陈观通敌底细。
  - When to use: 江面无船、敌人拘船守岸，正面无法渡军时。
  - How: 脱膊匾扎、携刀顶银；先夺船再审活口；问清"来情去意"后灭口，凿沉坐船。
- **假乘服色（真文书包装伏兵）**：用缴获的官诰、关防文书、三百面号旗、一千领号衣，让燕青扮叶虞候、穆弘扮陈益、李俊扮陈泰，把二万伏兵藏在三百只快船内。
  - When to use: 需要让大股兵马通过敌方盘查关口时。
  - How: 让最善应对者扮头目、持真公文，答话滴水不漏；船分三拨、偏将簇拥，伏兵匿于舱内。
- **药酒+号炮（不按君臣的药头）**：解珍解宝趁劝酒下药麻倒陈观父子，燕青放号炮为号，庄外十将、六将同时杀入。
  - When to use: 要在庄院内无声解决核心人物，又需外部接应同步时。
  - How: 劝酒下药→一人放炮→里外齐动手，先提首级再夺粮船。
- **祭奠折将以固军心**：宋江亲祭宋万，斩生擒的卓万里、和潼沥血享祭。
  - When to use: 军中折将、主帅情绪动摇时。
  - How: 排祭仪、亲自奠酒、以敌首级祭奠；吴用以"生死人之分定，何故烦恼"把情绪拉回大局。

## Key Concepts
- **吕师囊**：方腊东厅枢密使，原歙州富户，惯使丈八蛇矛，守润州江岸，部下十二统制号"江南十二神"。
- **寺裹山／山裹寺**：金山寺绕山而建、焦山寺藏于山凹的地理分别，是潜入路线的坐标。
- **瓜洲渡口**：长江北岸张顺下水处，"净荡荡地无甚险阻"。
- **陈将仕（陈观）**：扬州定浦村富户，结交方腊、献五万石粮与三百只船求封扬州府尹。
- **叶虞候（叶贵）**：吕师囊帐前虞候，被张顺所杀，燕青冒充其身份。
- **罡星入吴地分野**：司天太监浦文英奏报的天象，方腊因此降旨严查北来之人，反使吕师囊为接旨而中止搜船。
- **号衣、号旗、关防文书**：敌方识别凭证，被缴获后成为渗透的钥匙。
- **润州（今镇江）**：长江南岸"江南第一个险隘州郡"，此役克复的第一座城。
- **折了三将**：宋万、焦挺、陶宗旺阵亡；宋江独念宋万"梁山泊开创之时多亏此人"。

## Mental Models
- 当敌人据江守险、无船可渡时，用"一人潜水取情报"代替"大部队强攻"。
- 把缴获的敌方文书看作可复用的通行证，其价值在于让敌人自我延时。
- 当敌方已有疑心时，把"用备好的说辞逐条回答盘问"当作渗透者的核心动作。
- 把折将当作需要仪式化处理的组织事件，而非单纯的损失。

## Anti-patterns
- **因疑而不搜**：吕师囊明言"吾观你船上军汉，模样非常，不由人不疑"，却因圣旨到而中止搜船，把城门交给敌人。
- **把天象警示当确定情报**：方腊据罡星分野严查北来之人，反被利用其检查流程延误战机。
- **主帅怏怏不乐**：吴用直指"有伤玉体"，情绪主导会拖累决策。

## Worked Example
张顺夜伏金山寺。初春江边，四间草房俱闭，张顺掇壁钻入，向白头婆婆借宿，得知吕师囊已把船只尽拘过润州。夜里星月交辉，他脱膊匾扎白绢水裩，把衣巾与两大银拴在头上，腰插尖刀，从瓜洲下水，水中如走旱路，直赴金山脚下。伏在缆船内时，见一只小船锁着大索、无橹篙，"来得跷蹊"，便再下水钻至船边，一刀削落两个摇橹的，又砍死舱中一人，逼问剩下的干人吴成。吴成供出：定浦村陈观结交方腊，正月初七渡江投拜，又在苏州见御弟三大王方貌，领了官诰、三百面号旗、一千领号衣，约定献五万石白粮、三百只船。张顺问清陈观有子陈益、陈泰及数千人马，一刀结果吴成，摇船回瓜洲，取回衣物银子，把船砍漏沉江。柴进据此报宋江，吴用随即定下"先拿了陈观"之计。张顺以潜水—夺船—审俘三步，把一条无船可渡的死路变成整场战役的情报入口。

## Key Takeaways
1. 渡江作战先派水性好的人潜水摸清对岸船只、粮草与联络暗号。
2. 让最不像军人者扮敌方文官，一句乡谈、一个下拜即可骗过盘问。
3. 用真文书配合假身份，比伪造凭据更可信。
4. 号炮是同步信号，庄内下药、庄外举火，时间差决定成败。
5. 折将后立刻用公开仪式把损失转化为军心凝聚力。
