# 第七十五回：活阎罗倒船偷御酒 黑旋风扯诏谤徽宗

## Core Idea
招安败在文本与使者：诏书写"纳官、拆毁巢穴""天兵一至，龆龀不留"，张干办、李虞候又以监督之名一路挑衅；阮小七借"船漏"把御酒换成村醪，李逵从梁上跳下扯碎诏书。宋江点破症结："若以数句善言抚恤，我等尽忠报国，万死无怨"。

## Frameworks Introduced
- **诏书羞辱（文本失败）**：谈判文本不承认对方尊严，再好的使团也救不回。
  - When to use: 判断招抚是否有成算时先读措辞。
  - How: 张叔夜"须陪些和气、甜言美语……有几个性如烈火的汉子，一言半语冲撞便坏大事"；蔡京"不失朝廷纲纪"，高俅"赦宥罪犯引入京城必成后患"；诏书却写"天兵一至，龆龀不留"。
- **随行监督者（谈判负资产）**：使臣被敌方心腹"提拨"跟着，温和立场无法兑现。
  - When to use: 使团被安插监督者时。
  - How: 张干办是蔡府干办、李虞候是高府虞候；张叔夜"只好教这两位干办不去罢"，陈太尉"是心腹人，不带他去必然疑心"；二人责"宋江大似谁……甚是欺君"，船上骂水手"村驴"。
- **偷换御酒（恩典物证失效）**：先制造事故转移注意，再调包恩赐之物。
  - When to use: 对方以恩赐为名行羞辱时。
  - How: 阮小七"预先积下两舱水"，拔屑子叫"船漏了"，众人急救太尉过船"那里来顾御酒诏书"；阮小七"只怕有毒"，和瓶连饮四瓶，六瓶分与水手；"装上十瓶村醪水白酒，还把原封头缚了"。
- **以打促和**：先让对方"人亡马倒、梦里也怕"，再受招安"才有些气度"。
  - When to use: 对方把招安当施舍时。
  - How: 吴用"这番必然招安不成，纵使招安也看得俺们如草芥……那时方受招安"；事后传令"马军拴束马匹，步军安排军器，水军整顿船只……那时却再商量"。

## Key Concepts
- **陈宗善**：殿前太尉，招安正使；被扯诏惊吓"屁滚尿流"回济州。
- **张干办 / 李虞候**：蔡府干办、高府虞候，以"提拨"为名随行挑衅坏事。
- **张叔夜**：济州太守，主张"甜言美语"，劝"两位干办不去罢"。
- **十瓶御酒 / 龙凤担**：恩赐载体；真酒被喝掉，换村醪。
- **活阎罗阮小七**：船梢监督，积水装船漏、换御酒。
- **龆龀不留**：诏书威胁语，连孩童都不留。
- **童贯 / 崔靖**：童贯拜大元帅；崔靖因主张招安被问罪。

## Mental Models
- 把招安失败看作文本失败：威胁语比拒绝更能激反对方。
- 把随行监督者看作谈判负资产：每句话都在拆使臣的台。
- 把御酒看作恩典物证；调包即当众宣布"恩典是假的"。

## Anti-patterns
- **带仇视对方的监督者谈判**："甚是欺君""村驴"，一句话毁掉和气。
- **诏书写威胁语**："天兵一至，龆龀不留"。
- **情绪爆发当策略**：众将一齐发作，全靠宋江横身拦当护送太尉。

## Worked Example
忠义堂上一百七员头领跪听开读。萧让读诏："钱粮、军器、马匹、船只目下纳官，拆毁巢穴……违戾诏制，天兵一至，龆龀不留。"宋江已下皆有怒色。李逵从梁上跳下，夺诏扯碎，揪住陈太尉拽拳便打；宋江、卢俊义横身抱住。李虞候喝"这厮是甚么人"，李逵劈头揪打，问"诏书是谁说的话"，张干办答"皇帝圣旨"。李逵道："你的皇帝姓宋，我的哥哥也姓宋，你做得皇帝，偏我哥哥做不得皇帝！"众人把他推下堂。宋江叫取御酒"教众人沾恩"，倾入银酒海——却是村醪白酒。鲁智深提禅杖骂"把水酒做御酒来哄俺们吃"，刘唐、武松、穆弘、史进一齐发作，六个水军头领骂下关。宋江横身拦当，护送太尉下三关，拜伏道："实是草诏的官员不知我梁山泊里湾曲。若以数句善言抚恤，我等尽忠报国，万死无怨。"太尉一行飞奔济州，招安破裂。

## Key Takeaways
1. 判断招抚能否成功先读文本：威胁语比拒绝更激反对方。
2. 不要让敌方对头以"监督"之名随使团同行。
3. 恩赐之物是仪式物证；被调包后恩典即成羞辱。
4. 主帅误判会让众将怒火一并烧向他："哥哥你休执迷"。
