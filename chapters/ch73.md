# 第七十三回：黑旋风乔捉鬼 梁山泊双献头

## Core Idea
李逵凭一面之词认定宋江抢了刘太公女儿，砍旗抡斧几乎杀了寨主；宋江靠"对质"自证，用"负荆请罪"给毁谤者活路，再把"捉假宋江"变成赎罪任务。燕青则示范另一手：抓到剪径小贼先治伤、还刀、放起来问话，让他带路端掉牛头山。

## Frameworks Introduced
- **假名托姓**：强人"到处只称是宋江"，借梁山名号行劫。
  - When to use: 指控与成员行踪不符时。
  - How: 燕青"多有依草附木、假名托姓的在外头胡做"；细问"日平西时来，三更里去了"，为头的"矮小黑瘦"，循线查到牛头山王江、董海。
- **对质立誓**：当众立字据、以头作赌，把怒气变成可裁决的程序。
  - When to use: 被至亲指控且证人俱在时。
  - How: 宋江"同去面对，若对翻了就舒着脖子受你板斧"；裴宣写赌赛军令状二纸各执；刘太公道"不是"，满庄庄客齐声"不是"。
- **负荆请罪**：脱衣自缚、背荆杖拜伏请打，把"输头"换成可接受的赎罪。
  - When to use: 犯重过但众望其留时。
  - How: 燕青教"脱了衣服，麻绳绑缚，脊梁上背着一把荆杖，拜伏忠义堂前，告道：'由哥哥打多少'"；宋江令他捉假宋江、救回女儿方饶。
- **抓活口问路**：抓到剪径贼不急杀，治伤、还刀、放起来问。
  - When to use: 只知方位、需本地人带路时。
  - How: 燕青"如意子"一箭射中那汉右腿；李逵要砍，燕青"我且与你拔了这箭"，问出牛头山王江、董海；治疮还刀，让他带路十五里。

## Key Concepts
- **小厮扑**：燕青相扑"天下第一"，李逵"多曾着他手脚，以此怕他"。
- **乔捉鬼**：李逵冒称"蓟州罗真人徒弟"，砍死狄太公女儿与奸夫王小二。
- **赌赛军令状**：裴宣所写二纸，宋江与李逵各书字据互相收执。
- **杏黄旗 / 替天行道**：李逵砍倒杏黄旗、扯碎"替天行道"四字。
- **牛头山**：旧道院被王江、董海占住，"到处只称是宋江"。
- **如意子**：燕青弩箭名号，"弩弦稳放，叫声：'如意子，不要误我！'"

## Mental Models
- 听到指控先问体貌、时间、方位——"假名托姓"往往是真相。
- 把对质看作把情绪冲突转为程序：立字据、聚证人、当面裁决。
- 把"负荆请罪"看作给犯错者的退路，比割头更易被群体接纳。

## Anti-patterns
- **不细穷来历就发作**：李逵听一面之词便砍旗抡斧，对质输了头。
- **把"捉鬼"当真**：太公哭"留得我女儿也罢"，李逵还要"谢将"。
- **独自追凶**：宋江提醒"他是两个好汉……你只独自一个如何近傍得他"。

## Worked Example
李逵在荆门镇听刘太公说"宋江"抢走十八岁女儿，信以为真，回寨拔斧砍倒杏黄旗、扯碎"替天行道"，直奔宋江，被五虎将拦下。宋江不自辩，只道"同去面对"，叫裴宣写赌赛军令状二纸。到了刘家庄，只放宋江、柴进入院，李逵提斧立侧边等指认；刘太公道"不是"，满庄庄客齐声"不是"。李逵输了头要自割，燕青教他"负荆请罪"——脱衣自缚、背荆杖跪忠义堂前。宋江笑"我和你赌砍头，你如何却来负荆"，令他捉假宋江、救回女儿方饶。燕青一箭射中剪径汉右腿，治伤还刀、放起来问出牛头山王江、董海；二人由那汉带路夜上道院，燕青一棒打翻一贼、截住后门，李逵两斧砍倒二贼，割下两颗头拴在一处，救出刘太公女儿，烧了草房送回庄上。李逵以两颗贼头，赎了先前那一斧之罪。

## Key Takeaways
1. 被至亲指控时不靠自辩靠对质：立字据、聚证人、让指控者亲眼看结果。
2. 给犯错兄弟留"负荆请罪"台阶，再把赎罪变成具体任务。
3. 听到指控先问体貌、时间、方位——"假名托姓"往往是真相。
4. 抓到小贼先治伤、还刀、放起来问话，活口比死人更能带路。
