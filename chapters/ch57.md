# 第五十七回：徐宁教使钩镰枪 宋江大破连环马

## Core Idea
破优势不看谁更猛，看谁先把战场选好：宋江弃骑马、用步军十队把连环马引进芦苇荆棘，钩镰枪专钩马脚、挠钩手就势缚人——结构克制胜过正面硬碰。胜后收韩滔、败后呼延灼借兵青州，又引出三山合力。

## Frameworks Introduced
- **钩镰枪法（专用克制技术）**：马上九变、步行六路，另有林草暗法。
  - When to use: 敌方是连锁成阵的骑兵时。
  - How: 徐宁传"马上使这般军器，就腰胯里做步上来，上中七路，三钩四拨，一搠一分，共使九个变法"；步行"八步四拨荡开门户，十二步一变，十六步大转身，分钩镰搠缴；二十四步那上攒下，钩东拨西；三十六步浑身盖护"；又教"藏林伏草，钩蹄拽腿"三路暗法；不到半月教成五七百人。
- **十队诱敌＋钩镰挠钩**：把敌人引到你的场地，再按结构拆解。
  - When to use: "孙吴兵法却利于山林沮泽"、敌骑优势时。
  - How: 宋江"并不用一骑马军"，十队步军诱敌"都望芦苇荆棘林中乱走"；钩镰枪军士"每十个间着十个挠钩手"，"但见马到，一搅钩翻，便把挠钩搭将入去捉了"；三更先渡钩镰枪军士埋伏，四更渡步军，高埠竖炮架，平明隔水擂鼓。
- **子母炮扰敌**：用炮响把敌人的注意力切碎、阵形搅乱。
  - When to use: 诱敌分兵、使其"不战自乱"时。
  - How: 北边先响一声，呼延灼骂"这炮必是凌振从贼教他施放"；正北连珠炮响，一母炮接四十九子炮，"响处风威大作"，官军不战自乱。

## Key Concepts
- **钩镰枪**：破连环甲的专用兵器；马上七路九变、步行二十四步／三十六步，兼"钩蹄拽腿"暗法。
- **挠钩手**：与钩镰枪"每十个间着十个"，马被钩倒后"一齐搭住，芦苇中只顾缚人"。
- **十队步军**：刘唐杜迁、穆弘穆春、杨雄陶宗旺、朱仝邓飞、解珍解宝、邹渊邹润等十队下山诱敌。
- **七十二煞**：韩滔"也是七十二煞之数"，与梁山"义气相投"，入伙做头领。

## Mental Models
- 把"钩镰枪"看作专用技术：破连锁靠钩马脚的结构克制，不靠蛮力。
- 把"十队诱敌"看作先选战场：芦苇荆棘林是刻意选择的战场。
- 把"收编败将"看作补给线：解缚、陪话、旧友劝说、接家眷完聚。

## Anti-patterns
- **自负勇力**：呼延灼夸"便是那厮们全伙都来，也待怎生"，三更御赐马就被桃花山偷走。
- **恋战逐北**：解珍解宝两次诈败，呼延灼一追"两边钻出二十四把钩镰枪，着地卷将来"。

## Worked Example
三更，梁山先把使钩镰枪的军士过渡四面埋伏；四更渡十队步军，凌振杜兴在高埠竖炮架，徐宁汤隆执号带。平明宋江隔水擂鼓摇旗。呼延灼锁连环甲马杀来，韩滔哨探见南边、东南、西南接连竖起梁山旗号，呼延灼已觉"必有计策"。正北一声炮响，他骂"这炮必是凌振从贼教他施放"；继而西边又起四路人马，母炮接四十九子炮"响处风威大作"，官军不战自乱。呼延灼望北冲，宋江军兵"尽投芦苇中乱走"，三千连环甲马一齐跑发、收勒不住，卷入败苇折芦。胡哨响处，钩镰枪一齐举手，"先钩倒两边马脚，中间的甲马便自咆哮起来"；挠钩手一齐搭住，芦苇中只顾缚人。呼延灼夺路奔西北，穆弘穆春、解珍解宝两次诈败诱他，一追"两边钻出二十四把钩镰枪着地卷来"，只得逃去。宋江收军：三千甲马一半被钩倒剥皮"做菜马食"，二停好马牵上山；带甲军士尽被生擒。刘唐杜迁捉了韩滔，宋江亲解其缚、以礼陪话，令彭玘凌振说他入伙，韩滔做了头领，又修书往陈州搬取老小完聚。

## Key Takeaways
1. 破连锁靠专用技术（钩镰枪钩马脚、挠钩搭人），不靠蛮力。
2. 诱敌入伏是先选好战场（芦苇荆棘林），再把敌人赶进去。
3. 让降将变自己人：解缚、陪话、旧友劝说、接家眷完聚。
4. 结盟要三要素：共同威胁、旧日义气、利益分配。
