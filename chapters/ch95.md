# 第九十五回：张顺魂捉方天定 宋江智取宁海军

## Core Idea
强攻连折猛将之后，破局点不在更强的战将，而在"被征服者的日常渠道"——一支科敛粮船和三对扮作梢公梢婆的夫妻，把伏兵直接送进了城门。

## Frameworks Introduced
- **以祭设伏（吊孝反打）**：宋江西陵桥祭张顺，方天定差十员首将分南北两路来拿；樊瑞、马麟、石秀左右举火，阮小二阮小五孟康截北山归路，李逵鲍旭项充李衮截定香桥。
  - When to use: 公开吊孝而预判敌方必来偷袭时。
  - How: 两侧先埋伏→火起为号→分头截断归路→夺马五百余匹回山。
- **识破回马诈输**：关胜战石宝二十余合，石宝回马便走，关胜勒马不追；吴用点明"此人惯使流星锤，回马诈输，漏人深入重地"。
  - When to use: 敌将武艺不弱却突然回马时。
  - How: 判为诱敌而非溃败，收军回寨，不使主将脱离阵势。
- **粮船混城（梢公梢婆伏兵）**：用袁评事被科敛的五千石粮船，王英、孙新、张青扮梢公，扈三娘、顾大嫂、孙二娘扮梢婆，军器埋舱，随搬粮混入城中；凌振在吴山顶放连珠炮，各门举火。
  - When to use: 城门坚闭、强攻折将，而敌方有日常粮运通道时。
  - How: 争取运粮者→主仆梢公混杂→军器埋舱→入城搬运时即在城内→炮响火起为号→水军从湖门登城。
- **付体收束（张顺魂捉方天定）**：张顺幽魂被西湖震泽龙君收为金华太保，借张横身壳，在五云山下扯方天定下马割头。
  - When to use: 需为阵亡者未竟之功给出因果闭环时。
  - How: 托梦→水府为神→附体杀敌→还魂说明，四段收束。

## Key Concepts
- **袁评事**：富阳县解粮官，被方天定科敛白粮五万石，先敛五千石押解，哭诉"大宋良民，累被科敛"。
- **连珠炮／九箱子母炮**：凌振在吴山顶施放，为各门齐攻的信号。
- **三对夫妻**：王英扈三娘、孙新顾大嫂、张青孙二娘，扮梢公梢婆混入城中。
- **候潮门三重门关**：外一重闸板、中两扇铁叶大门、里一层排栅门，刘唐抢入被闸板连马砸死。
- **厉天闰**：镇国大将军，救独松关，斩周通、刺死张清、剁董平，后被卢俊义杀死。
- **金华太保**：张顺死后所受水府神职，附体张横杀方天定。
- **折了九将**：董平、张清、周通、雷横、龚旺、索超、邓飞、刘唐、鲍旭。

## Mental Models
- 把"被科敛的良民"看作可被策反的运输渠道，他们的日常劳作就是最好的伪装。
- 当强攻连折猛将时，停止堆叠兵力，改找城里人的日常流程。
- 把"回马诈输"当作默认怀疑对象，敌将越强越要疑。
- 把复仇冲动换算成成本，每一次"不捉得他不回来见哥哥"都在增加折将数。

## Anti-patterns
- **伤未愈擅自出战**：董平左臂中炮风，瞒卢俊义与张清步战上关，枪搠松树拔不出，被厉天闰刺死、张韬剁两段。
- **抢头功**：刘唐一人飞马抢入候潮门，被闸板连马砸死。
- **追诈败**：索超未及十合追石宝，脸上中锤落马；邓飞去救，被一刀砍两段。
- **醉饱请战**：李逵等吃得半醉"把性命作戏"，虽斫断马脚仍折鲍旭。

## Worked Example
粮船智取宁海军。解珍、解宝哨到南门外范村，见江边泊着数十只粮船，是富阳县袁评事解送的五千石白粮。袁评事哭诉"我等皆大宋良民，累被方腊不时科敛，但有不从者全家杀害"，解珍不忍杀他，带回报告。吴用大喜"此乃天赐其便"，令解珍解宝带凌振并八员偏将，王英、孙新、张青扮梢公，扈三娘、顾大嫂、孙二娘扮梢婆，军器埋在船舱。袁评事叫开城门，方天定差吴值点船，又差六将引一万军拦住东北角，众将扮作水手随粮入城搬运。当夜二更，凌振在吴山顶放起九箱子母炮，众将到处点火，城中鼎沸，各门军士逃命，李俊、石秀从涌金门首先登城。方天定从南门逃至五云山下，江里跳起一个衔刀之人——张顺附体张横，扯方天定下马割头，骑其马奔回城中见宋江。一支被胁迫的粮船，成了打开宁海军的钥匙。

## Key Takeaways
1. 强攻连折猛将后停手，去找敌方日常流程里可利用的环节。
2. 被压迫的运粮者是天然盟友，哭诉就是策反入口。
3. 敌将回马先判为诱敌，越强的将越不追。
4. 伤未愈、抢头功、醉饱请战都是把复仇变成折将的捷径。
5. 用炮响与火起作同步信号，各门一齐动手使敌首尾不能相顾。
