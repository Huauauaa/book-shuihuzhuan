# 第八十六回：宋公明大战独鹿山 卢俊义兵陷青石峪

## Core Idea
贺重宝用"连败诱敌＋青石峪口袋＋妖法遮蔽"设下陷阱，宋江卢俊义以"连输数次如何是诱敌"轻敌中计；解围靠的不是正面勇猛，而是"扮猎户侦察—本地人指路—白胜滚山报信—公孙胜破妖—步军扒口"的多层信息链。

## Frameworks Introduced
- **连败诱入（口袋阵）**：贺重宝判"打了俺三个大郡，气满志骄，必然想着幽州"。
  - When to use: 对方连胜气骄、贪于取城时。
  - How: 分兵"都不要赢他，只佯输诈败，引入幽州境界"；青石峪"只一条路入去，四面尽是高山，并无活路"，外圈大军合围，"必然饿死"。
- **识破诱敌**：吴用朱武"幽州分兵两路而来，此必是诱引之计，且未可行"，卢俊义以"连输了数次如何是诱敌"、宋江以"势穷力尽"驳回——反面案例。
  - When to use: 敌军连续不战自退时。
  - How: 把"连败"读作诱饵而非实力信号，查明再动。
- **扮猎户侦察**：解珍解宝披虎皮袍、拖钢叉，投宿猎户刘二刘三家，煮獐肉暖社酒，亮明梁山身份。
  - When to use: 需摸清被困部队位置与地形时。
  - How: 伪装同类→亮明身份（"替天行道不损良民"的口碑作通行证）→套出"青石峪只一条路、填石封口"、峪口"两株大柏树形如伞盖"、"提防贺统军妖法"三件情报。
- **破妖扒口**：公孙胜识妖，念咒喝"疾"，步军扒开填塞的青石出口。
  - When to use: 敌方以妖法遮蔽、以石块封路时。
  - How: 公孙胜"知道此是妖法"，马上掣剑念咒，"狂风扫退浮云，现出明朗朗一轮红日"；李逵双斧砍马脚、樊瑞鲍旭蛮牌撞阵，步军扒口杀入。

## Key Concepts
- **贺重宝**：副统军，善行妖法，使三尖两刃刀，守幽州提督诸路军马。
- **青石峪 / 独鹿山**：青石峪只一路、四面悬崖，出口被大块青石填塞。
- **阴云闭合、黑雾遮天**：妖法"白昼如夜，不分东西南北"。
- **公孙胜破妖**：宝剑指定、喝"疾"，红日重现。
- **两株大柏树**："形如伞盖，四面尽皆望见"，即青石峪口地标。
- **白胜滚山**：重毡裹定、绳索拴紧从山顶滚下报信。

## Mental Models
- "连败"往往不是对方弱，而是把你往口袋里引；越顺手越要查地形、听军师预警。
- 脱困是信息链：伪装侦察→本地人指路→冒死通信→技术破障→工兵清路。
- 地标的价值在"四面尽皆望见"：大柏树把模糊的峪口变成可协同的目标。

## Anti-patterns
- **以连败判敌弱**：卢俊义"那厮连输了数次，如何是诱敌之计"，正合贺重宝"气满志骄"之算。
- **无视军师预警**：吴用朱武已明言"此必是诱引之计"，仍引兵往幽州便进。
- **分兵无接应**：宋江未预设两翼，关胜追出四五十里才"急叫回军"，已被撞做两段。

## Worked Example
贺重宝以贺拆、贺云连败诱敌，卢俊义以"连输数次如何是诱敌"说服宋江进兵。关胜追贺统军四五十里，四面战鼓齐响，宋江兵被撞做两段；卢俊义围中遇妖法白昼如夜，循鸾铃赶入山口，风静后四面悬崖——正是青石峪，徐宁索超等十二头领并五千军马无路可出、无粮可济。宋江这厢由公孙胜念咒喝"疾"扫退妖云，退守独鹿山，遣解珍解宝披虎皮袍扮猎户入山，投宿刘二刘三家，社酒獐肉间套出峪口大柏树与提防妖法；白胜以重毡裹身从山顶滚下报信："迟则诸将必然死矣。"宋江连夜引军望大柏树杀去，林冲搠死贺拆、李逵砍断贺云马脚，贺统军妖法被公孙胜一喝扫退，步军扒开青石杀入。卢俊义见宋江军马，大哭"若不得仁兄垂救，几丧兄弟性命"。

## Key Takeaways
1. "连败"常是诱饵：越顺手越要查地形、听军师预警。
2. 脱困靠信息链：侦察→指路→通信→破障→清路。
3. 把模糊位置变成"四面望见"的地标，部队才能协同。
4. 解围先休赶穷寇、将息被困人马，再取城。
