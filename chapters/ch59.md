# 第五十九回：吴用赚金铃吊挂 宋江闹西岳华山

## Core Idea
城坚濠深，就"借"朝廷威仪骗开城门：吴用截住宿太尉，借御香与金铃吊挂扮钦差，把贺太守赚到西岳庙割头——权威一旦被借来，"见不见"都成了送命礼节。

## Frameworks Introduced
- **借权威的六步流程**：求见、示威、借物、乔装、取信、动手。
  - When to use: 城池坚牢、"急切难打"、必须里应外合时。
  - How: 探子报宿太尉赍金铃吊挂来西岳降香，吴用"计在这里了"；水路截船，宋江躬身"梁山泊义士宋江谨参祗候"，号旗一招岸上四将搭弓、李俊张顺在水面把虞候攧下又送上船；聚义厅下四拜借"御香仪从并金铃吊挂去赚华州，事毕拜还"，又许"太尉回京都推在宋江身上"；拣小喽啰扮宿元景"装做染病"，宋江吴用扮客帐司，解珍解宝杨雄石秀扮虞候，花荣徐宁朱仝李应扮衙兵；以金铃吊挂与中书省公文取信推官；赚贺太守入庙，吴用喝"拿下"，解珍解宝割头。
- **截船的分级施压**：礼、兵、水戏、誓词层层加码。
  - When to use: 对方是朝廷命臣、不肯轻易登岸时。
  - How: 先"躬身唱喏""不敢造次"；再"只怕孩儿们惊了太尉"、号旗一招弓箭摆列；再令李俊张顺把虞候攧下水又送上船，唬得太尉"魂不着体"；最后"若怀此念，西岳神灵诛灭"——"不容太尉不上岸"。
- **预言兑现（遇宿重重喜）**：把偶遇纳入天命叙事，角色据此行动。
  - When to use: 法术／天命体系中某个姓氏被预告时。
  - How: 宋江见黄旗"太尉宿元景"，暗喜"昔日玄女有言：'遇宿重重喜。'今日既见此人，必有主意"。

## Key Concepts
- **金铃吊挂**：御赐西岳圣帝殿正中悬挂之物，"浑金打就，五彩装成……七宝珍珠嵌造"，东京内府高手匠人制成。
- **宿太尉／宿元景**：奉圣旨西岳降香的殿司太尉；回京奏"宋江先在途中劫了御香、吊挂，因此赚知府到庙"。
- **贺太守**：华州太守、蔡太师门人；以"请赴斋"赚鲁智深，本回被赚到西岳庙割头。

## Mental Models
- 把"借权威"看作工具化流程：求见、示威、借物、乔装、取信、动手，缺一不可。
- 把"截船"看作分级施压：礼、兵、水戏、誓词层层加码，让人"不容不上岸"。
- 把"偶遇"看作叙事框架，给行动以信心。

## Anti-patterns
- **孤身刺太守**：鲁智深自解禅杖戒刀，"府堂深处如何许你带刀杖入去"，落入三四十做公的包围。
- **轻敌滚牌**：项充、李衮"直滚入阵来"，史进折了一半人马。

## Worked Example
宋江、吴用夜探华州，见"城高地壮，堑濠深阔"，朱武说"急切难打，只除非里应外合"。探子报宿太尉赍金铃吊挂来降香，吴用定计：李俊、张顺、杨春先夺大船藏于渡口，宋江等埋伏岸上。天明官船到，黄旗写"西岳降香太尉宿元景"，宋江暗喜"遇宿重重喜"。客帐司拒绝相见，朱仝号旗一招，岸上四将搭箭；宿太尉出船头，李俊张顺把虞候攧下水又送上船，唬得他魂不着体。宋江扶他上马到聚义厅，下四拜借仪从："去赚华州，事毕拜还……太尉回京都推在宋江身上。"宿太尉推托不得。于是小喽啰扮宿元景"装做染病"，宋江吴用扮客帐司，解珍解宝杨雄石秀扮虞候，花荣徐宁朱仝李应扮衙兵，抬着金铃吊挂直奔西岳庙。推官见内府仪仗信以为真，回报贺太守。贺太守带三百余带刀公吏入庙，吴用喝"拿下"，解珍解宝一脚踢翻割头；花荣等把三百余人"算子般都杀倒"，武松石秀在庙门截杀。城中火起，宋江杀入牢中救出史进、鲁智深，取回禅杖戒刀——玉娇枝早已投井而死。

## Key Takeaways
1. 借权威是流程：求见、示威、借物、乔装、取信、动手，缺一不可。
2. 截人分级施压：礼、兵、水戏、誓词层层加码，让人"不容不上岸"。
3. 把偶遇纳入预言（"遇宿重重喜"），给行动以信心与合理性。
4. 异常环境（青色灯笼）是敌方能力的线索：先退兵、再设阵。
