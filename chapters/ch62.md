# 第六十二回：放冷箭燕青救主 劫法场石秀跳楼

## Core Idea
同回两条营救线：燕青"跟定、疑异、预埋"两弩箭救主于董超、薛霸之手；石秀"占楼、待时、一声和里跳楼"孤身劫法场。都把救做成关键时点的单点突袭；蔡福则周旋于买凶与行金之间，示范双面下注的生存术。

## Frameworks Introduced
- **跟踪预埋救主**：从异常会面预判下手地点，提前埋伏、一击致命。
  - When to use: 押送途中预计公人将动手时。
  - How: 燕青"直从留守司前跟定"，见李固请公人便"疑猜这厮们要害主人"，连夜跟出城；村店里伏在壁子缝看尽作贱；料定"必来这林子里下手"，先到松林等候，两弩箭结果董超、薛霸。
- **孤身劫法场**：侦察地形、占制高点、以口号造乱、趁乱拖人。
  - When to use: 大部队来不及、必须单点突入时。
  - How: 石秀问老丈知"午时三刻市曹斩卢俊义"，到十字路口酒楼临街占阁儿，叫"大碗酒，大块肉"坐等；孔目读罢犯由牌、众人齐和一声，掣刀大呼"梁山泊好汉全伙在此"，跳下砍翻十数人，拖卢俊义投南便走。
- **狱卒双面下注**：两边受贿、审时度势、选"周全性命"一边并打通关节改判。
  - When to use: 买凶者与营救者同时送钱、各带威胁时。
  - How: 蔡福先收李固五百两金答应"明日早来扛尸"；柴进又以一千两黄金并"打破城池尽皆斩首"之威逼来；蔡福以"杀人须见血，救人须救彻"买上告下，让张孔目以"虽有原告，却无实迹"改判"脊杖四十，刺配三千里"。

## Key Concepts
- **浪子燕青**：卢俊义心腹，被逐后沿路乞饭送监、跟定公人，以川弩三箭救主。
- **拚命三郎石秀**：与杨雄奉命探消息，独自入城劫法场，勇而寡谋。
- **铁臂膊蔡福／一枝花蔡庆**：北京押牢节级兄弟兼刽子，受贿而终周全卢俊义。
- **小旋风柴进**：大周皇帝嫡派子孙，奉宋江令行金一千两，兼"兵临城下"之威。
- **董超、薛霸**：曾押林冲、今押卢俊义，是"山泊之始与终"的关锁。
- **沙门岛**：远配之地，"往回六千馀里"，李固买凶欲途中结果卢俊义。

## Mental Models
- 人被押送、消息传不出去时，用"跟定—疑异—预埋"把救压缩成林中一瞬。
- 把燕青射喜雀问卦看作信息困境中的仪式：最后一枝箭既求食，又指路。
- 把蔡福受贿看作风险定价：一百两买杀、一千两买救且附灭城威胁。

## Anti-patterns
- **轻信至亲**：卢俊义踢倒燕青、骂"休来放屁"，拒绝相信妻子与李固的背叛。
- **买凶自以为稳**：李固以为买通公人便万无一失，不知燕青跟踪、柴进行金。
- **劫法场无退路**：石秀不认北京路、卢俊义走不动，终究被挠钩套索绊翻。

## Worked Example
石秀只带随身衣服来到北京城外，次早入城，见人人嗟叹、家家闭户。问市口老丈，才知卢员外"迭配沙门岛、路上坏了两个公人"，今日午时三刻押赴市曹斩首。石秀径到十字路口酒楼，临街占个阁儿，叫"大碗酒，大块肉，只顾卖来"；酒保催他回避，他睁着怪眼喝"我怕甚么鸟！你快走下去"。不多时锣鼓喧天，卢俊义被押到楼前跪下，蔡福拿着法刀、蔡庆扶住枷梢；孔目高声读罢犯由牌，众人齐和一声——就在这一声里，石秀掣腰刀大叫"梁山泊好汉全伙在此"，从楼上跳将下来，手举钢刀砍翻十数个，一手拖住卢俊义投南便走。然而石秀不认得北京的路，卢俊义又惊得呆了、越走不动；梁中书关了四门，做公的合拢来，两人被挠钩搭住、套索绊翻，尽数捉了。一声口号能撕缺口，没有认路与体力，终究寡不敌众。

## Key Takeaways
1. 预判对方在何处下手，提前埋伏比全程硬拼更省力。
2. 消息送不出去时，用仪式动作（射雀问卦）把最后资源变成问路工具。
3. 居中者可两头收钱，再用"价格＋后果"定价选边，把死刑改成刺配。
4. 劫法场要占制高点、用虚张口号造乱，但必须先备撤退路线。
