# 第十二回：梁山泊林冲落草 汴京城杨志卖刀

## Core Idea
杨志两次"求职"都不靠人情：在梁山只要回被夺行李、拒绝入伙；在东京把盘缠全押在复职上却被高俅一笔批倒。卖刀杀人后他主动出首、借众邻证词把死罪改写成"误伤人命"，显示失败者如何用程序意识守住底线。

## Frameworks Introduced
- **最小请求式拒绝**：不接受招揽时只提可执行的最小诉求，不争论价值。
  - When to use: 对方以礼遇和利益挽留，而你另有目标。
  - How: 王伦劝"大秤分金银，大碗吃酒肉"，杨志只答"望众头领还了洒家行李，如不肯还，杨志空手也去了"。
- **借第二强者制衡第一强者**：用新人稀释原威胁，又向荐主示好。
  - When to use: 已有一名你压不住的投奔者，又来同等量级的人。
  - How: 王伦心想"若留林冲，实形容得我们不济，不如留杨志，与他作敌"；杨志不愿，次日仍还行李、送出大路。
- **自首框定叙事**：第一时间投案、拉见证人，重写事件定性。
  - When to use: 冲突已致死，且对方是公认恶人。
  - How: 杨志叫"街坊邻舍都是证见"，杀牛二后"都来同洒家去官府里出首"；推司以"与民除害"改招"一时斗殴杀伤，误伤人命"。

## Key Concepts
- **青面兽杨志**：杨令公之孙，面皮一搭青记；应武举，官至殿司制使。
- **花石纲**：十制使赴太湖搬运，杨志黄河翻船失陷，难以复职。
- **没毛大虫牛二**：京师破落户泼皮，撒泼行凶，开封府也治他不下。
- **宝刀三件**：砍铜剁铁不卷刃、吹毛得过、杀人刀上没血；插草标上市。
- **天汉州桥／开封府出首**：卖刀现场与自首去处，众邻舍供状。
- **迭配北京大名府**：断二十脊杖、刺两行金印后充军；宝刀没官入库。
- **梁中书**：蔡京女婿，大名府留守；认得杨志，当厅开枷留用。

## Mental Models
- 把"拒绝"看作交易：杨志不要酒不要入伙，只要回行李——给出最小可执行诉求。
- 把"留用第二强者"看作制衡：王伦"留了杨志，与他作敌"。
- 把"自首"看作法律叙事重构：主动投案＋众证＋民意，把死罪改写成误伤。

## Anti-patterns
- **把全部盘缠押在单一渠道**：杨志"买上告下，把许多东西都使尽了"才被一笔批倒。
- **对无赖讲证据**：三件宝刀都验成了，牛二仍"我不信""你好男子，剁我一刀"。
- **把赦免当护身符**："虽经赦宥所犯罪名，难以委用"，旧账在掌权者手里不作废。

## Worked Example
杨志到东京，央人去枢密院"买上告下"，把金银使尽才得见高太尉。高俅翻旧账："十个制使去运花石纲，九个回到京师交纳了，偏你这厮失陷了，又不来首告"，一笔批倒。盘缠已尽，杨志只得以祖传宝刀插草标上市，马行街立两个时辰无人问，转到天汉州桥撞上没毛大虫牛二。牛二扯刀问价，杨志索三千贯，列出砍铜不卷、吹毛得过、杀人刀上没血三件好处；牛二讨铜钱剁开、拔发吹断，众人喝采，却逼第三件"你敢杀我"。杨志只推他一交，又当街叫"街坊邻舍都是证见……这个泼皮强夺洒家的刀，又把俺打"，满城人怕牛二，无人敢劝。牛二挥拳打来，杨志躲过，持刀抢入，颡根一搠、胸脯两刀，牛二倒地。杨志随即说"都来同洒家去官府里出首"，拉众邻舍径投开封府，终以误伤人命刺配大名府。

## Key Takeaways
1. 拒绝招揽时只提最小请求，既保资源也不给人情把柄。
2. 破格用人前先公开验证：梁中书设教场演武，把偏爱变成众望所归。
3. 掌权者的旧账不因赦免消失，复职前先留退路。
4. 演示式说服只对愿承担检验成本者有效，先判断对方有无底线。
5. 闯祸后立即框定叙事：主动出首、拉见证人，能改写定性。
