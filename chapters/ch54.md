# 第五十四回：入云龙斗法破高廉 黑旋风探穴救柴进

## Core Idea
破敌不只靠更强的法术，更靠"识破构成"与"借势取城"：高廉的怪兽原是白纸剪的，求救原是可乘之机；救柴进的张力不在战斗，而在于每近一步多一跌——直到井底传出"口内微微声唤"。

## Frameworks Introduced
- **授法带诫**：交出强力工具时，同时给出边界条件与后顾之忧的安排。
  - When to use: 把关键能力交给一个人、又要他专注赴任时。
  - How: 罗真人传公孙胜"五雷天罡正法"，令"保国安民，替天行道。休被人欲所缚"；又授八字"逢幽而止，遇汴而还"，嘱"休得临期有误"；并许"你的老母，我自使人早晚看视"。
- **识破构成**：恐怖手段先还原原理，再一击破之。
  - When to use: 敌方妖法、烟幕让你无法硬拼时。
  - How: 高廉敲聚兽铜牌卷黄砂放怪兽，公孙胜掣松文古定剑念咒喝"疾"，一道金光，怪兽坠于阵前——"却都是白纸剪的虎豹走兽，黄砂尽皆荡散不起"。
- **将计就计（诈救兵取城）**：放求救者走，比困住他更有价值。
  - When to use: 敌据坚城、兵微将寡、专等外援时。
  - How: 吴用"且放他去，可以将计就计"，令两枝人马诈作救兵"于路混战，高廉必然开门助战。乘势一面取城，把高廉引入小路"；高廉果开门中伏，驾黑云逃走，被公孙胜剑指落云、雷横一朴刀挥为两段。

## Key Concepts
- **五雷天罡正法**：罗真人传公孙胜的正法，破高廉妖术，"保国安民，替天行道"。
- **逢幽而止，遇汴而还**：罗真人八字诫，公孙胜行动边界的预言式约束。
- **金钱豹子汤隆**：延安知寨之后、打铁出身、浑身麻点，使三十斤铁瓜锤；武冈镇被李逵结拜带上山。
- **松文古定剑**：公孙胜法剑，指敌念咒破纸虎黄砂。
- **枯井**：高唐州后牢八九丈深井，蔺仁奉命害柴进不忍下手，开枷推入躲避。

## Mental Models
- 把"正法"看作带边界的授权：能力越强，越要配套诫语与后勤安排。
- 把"求救"看作可乘之机：敌人派出去搬兵的使者，反过来是你取城的钥匙。
- 把"恐怖"看作可还原的构成：怪兽是白纸剪的，破法在识破原理。

## Anti-patterns
- **自负妖术**：高廉"数年学得术法，不想今日被他破了"，又轻信救兵，弃城被杀。
- **喜新忘旧**：柴进刚救上井，李逵还在底下发喊——宋江忘了放箩，被当面抱怨"你们也不是好人"。

## Worked Example
宋江克城传令"休得伤害百姓"，去大牢救柴进；牢中只有柴皇城与沧州提捉来的两家老小，独独不见柴进。当牢节级蔺仁禀道：高廉分付"但有凶吉，你可便下手"，他见柴进是好男子不忍下手，先推病至八分，后回称已死；恐差人看视见罪，昨日引柴进到后面枯井边，开枷推放里面躲避。众人到井边，黑洞洞约八九丈深，上面叫无人应；宋江垂泪"眼见得多是没了"。吴用问谁敢下去，李逵大叫"等我下去"，宋江道"当初也是你送了他，今日正宜报本"。李逵脱得赤条条，拿两把板斧坐进大篾箩，索上缚两个铜铃，放到底下。他摸着一堆骸骨，叫"爷娘，甚鸟东西在这里"；再摸，底下湿漉漉的，一摸摸着一个人墩在水坑里，叫"柴大官人"不见动，把手去摸只觉"口内微微声唤"——"谢天地，恁的时还有救性！"摇铃上来，宋江令他再下去把柴进放箩里先发上来。李逵道"我去蓟州，着了两道儿，今番休撞第三遍"，宋江笑"我如何肯弄你"；他只得再下抱柴进上来。柴进头破额裂、两腿打烂；李逵在井底发喊，宋江才急叫放箩下去。

## Key Takeaways
1. 交出强力能力要配套边界条件（八字诫）与后勤安排（安置老母）。
2. 敌人求救时，放他走比困住他更有价值——用假救兵换真城池。
3. 面对看似不可战胜的手段，先还原其构成（白纸怪兽）。
4. 设计救援场景可用"逐步作跌"，最后一刻才给生还信号。
