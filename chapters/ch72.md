# 第七十二回：柴进簪花入禁院 李逵元夜闹东京

## Core Idea
潜入要借现成身份而非伪造：柴进灌醉班直穿上宫花锦袄入禁院刻去"山东宋江"，燕青以"山东巨富"加百两黄金撬开李师师之门。但"好歹惹事"的李逵脱离看管，招安探路变成火烧青楼、全城喊杀——吴用早已"克时定日"埋下一千骑接应。

## Frameworks Introduced
- **借服色潜入**：取用有权者的整套服饰凭证。
  - When to use: 关卡只认服色时。
  - How: 燕青灌醉王班直，柴进"脱下锦袄、踢串、鞋裤，从头穿了，戴上花帽，拿了执色"，过禁门"无人阻当"。
- **掮客开路**：先让中间人获利，再让目标出场。
  - When to use: 求见名妓权贵无门路时。
  - How: 燕青冒称"张闲"，伏侍"山东第一有名财主"、"有千百两金银送宅上"；虔婆动心，即叫李师师出来；十五夜先送黄金一百两换得入席。
- **预埋接应**：潜入前预设撤退路线与兵马。
  - When to use: 深入敌都、暴露风险高时。
  - How: 吴用差关胜、林冲、秦明、呼延灼、董平引一千骑城外等接，带空马；五虎将立马濠堑大吼"梁山泊好汉全伙在此"，高太尉"慌忙放下吊桥"。
- **看管不可控变量**：给惹事者配专人，脱手即引爆。
  - When to use: 团队中有"好歹惹事"的成员时。
  - How: 燕青"专和李逵作伴"，席间打抹他和戴宗去门前坐地；燕青随主入阁后，李逵提交椅打翻杨太尉、点书画放火，夺棒打出小御街。

## Key Concepts
- **美玉灭癍**：安道全点去宋江刺字，再用良金美玉细末涂搽消磨。
- **班直 / 宫花锦袄**：禁中值宿军士簪翠叶金花、金牌"与民同乐"。
- **睿思殿四大寇**：御书"山东宋江，淮西王庆，河北田虎，江南方腊"，柴进刻去"山东宋江"。
- **李师师 / 虔婆李妈妈**：上厅行首与徽宗相好；虔婆好利，是开门枢纽。
- **高太尉**：引铁骑五千巡禁，追至城外被五虎将吓退。

## Mental Models
- 进入只认服色的禁地，用"借来的身份"而非"编造的身份"。
- 把掮客看作把金钱转换为接触机会的转换器。
- 把"大闹东京"看作计划的一部分：表面失控、实有撤退部署。

## Anti-patterns
- **带惹事者进敏感区**：宋江抵不住李逵"抵死要去"，终致火烧李师师家。
- **禁中久留求口招**：遇"官家从地道中来至后门"；柴进"便是应允了，后来也有翻变"。
- **公开狂言**：史进、穆弘在樊楼高歌"不斩奸邪誓不休"，被宋江喝退。

## Worked Example
十五夜，宋江、柴进、戴宗、燕青、李逵从万寿门入城。燕青先送黄金一百两，宋江得以入李师师阁中饮酒，作词"六六雁行连八九，只等金鸡消息"，盼徽宗备细问其好求招安。不期奶子报"官家从地道中来至后门"，宋江等闪在暗处错过机会。李逵被留在门前，见宋江、柴进与美色妇人吃酒，"头上毛发倒竖起来"。杨太尉揭帘喝问，李逵提起交椅劈脸打来，扯书画点着放火，香桌椅凳打得粉碎。宋江等赶出，只得扯出门外；李逵街上夺棒，直打出小御街。穆弘、史进、鲁智深、武松、朱仝、刘唐先后杀入接应；吴用预埋的关胜等五虎将引一千骑恰在城外，大吼"梁山泊好汉全伙在此"，高太尉慌忙放下吊桥。宋江率军先回，留燕青等李逵——却见李逵手提双斧，独自要去打东京城池。

## Key Takeaways
1. 潜入禁地要借值宿者整套服色与执色，并备好"他醉了"的话术。
2. 求见高不可攀之人，先让看门人获利，再用礼物买出接触机会。
3. 高风险潜入必须克时定日预埋接应：屯骑、空马、主帅先撤。
4. 对惹事随行者配专人看管，看管一松变量就引爆。
