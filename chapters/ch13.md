# 第十三回：急先锋东郭争功 青面兽北京斗武

## Core Idea
梁中书要把"我偏爱杨志"变成"众将服气"，用一套可验证、可量化、留有余地的演武程序达成；知县时文彬又用"红叶为凭"防巡捕虚报。本回的可迁移点是：把主观判断转化为公开程序与可核验的凭证。

## Frameworks Introduced
- **安全化比试设计**：先消除不可逆伤害，再设可度量指标。
  - When to use: 内部比武需见真章，又不能真伤人。
  - How: 闻达主张"去了枪头，各用毡片包裹，地下蘸了石灰……如白点多者当输"；杨志四五十合只左肩一点白，周谨"斑斑点点约有三五十处"。
- **二次考核保全失败者**：用第二科目给败者台阶，让胜者赢得彻底。
  - When to use: 一道题淘汰会让人认为不公、"慢了军心"。
  - How: 李成以"周谨枪法生疏，弓马熟闲"为由请比箭；杨志三箭全避，反手一箭"只射他不致命处"，周谨落马。
- **可核验的行程凭证**：以现场独有的物证替代口头汇报。
  - When to use: 派员在外执行任务，需防虚报。
  - How: 时文彬令朱仝、雷横分头巡捕，"东溪村山上有株大红叶树，别处皆无……各人若无红叶，便是汝等虚妄"。

## Key Concepts
- **急先锋索超**：大名府正牌军，性急"撮盐入火"；替徒弟周谨出头。
- **周谨**：副牌军，比枪、比箭皆败；索超称其"患病未痊，精神不在"。
- **李天王李成／闻大刀闻达**：两名都监，一个设计去枪头比法，一个恐伤鸣锣。
- **管军提辖使**：杨志、索超比武后同升的职役；各赏两锭白银、两副表里。
- **石灰比枪／遮箭牌／镫里藏身**：安全比试与闪避动作。
- **生辰纲**：蔡夫人提醒六月十五生辰，梁中书已备十万贯，上年一遭"尽被贼人劫了"。
- **时文彬／美髯公朱仝／插翅虎雷横**：郓城知县与两位都头，分头巡捕。

## Mental Models
- 把"比试"看作制度设计题：先去掉不可逆伤害，再定可量化指标。
- 把"赢者通吃"看作不稳：给败者二次机会，比直接淘汰更稳军心。
- 把"上级偏爱"看作需程序背书：梁中书"只恐众人不伏"，用演武把偏爱变成公认。

## Anti-patterns
- **凭意气挑战**：索超"撮盐入火"，为替徒弟争面子立誓，几乎以性命相搏。
- **赶尽杀绝式胜利**：杨志若真射后心窝，一次考核就变成命案。
- **只听汇报不验证**：知县要用红叶堵"虚妄"，说明口头回报不足为凭。

## Worked Example
闻达喝住即将交锋的周谨、杨志，主张"军中自家比试，恐有伤损"，去掉枪头、毡片包裹、蘸石灰、穿皂衫，以白点多者当输。杨志四五十合只左肩一点白，周谨身上三五十处。梁中书要杨志截替周谨职役，李成以"恐怕慢了军心"请再比箭。杨志让周谨先射三箭：一箭"镫里藏身"躲过，二箭用弓梢拨落草地，三箭"扭回身就鞍上只一绰，绰在手里"。轮到杨志，他先虚扯一扯，骗得周谨举傍牌来迎；第二箭"弓开如满月，箭去似流星"，只中左肩，周谨翻身落马。索超随即出列，称周谨"患病未痊"，愿代师殿后。梁中书与李成各借战马披挂，两人斗五十馀合不分胜败，闻达恐伤鸣锣叫停。李成、闻达禀"两个武艺一般，皆可重用"，梁中书将两个同升管军提辖使，众军卒打得胜鼓而散。

## Key Takeaways
1. 内部考核先做安全化设计，去掉不可逆伤害再定量化指标。
2. 让败者体面退出：加一场二次考核，比直接淘汰更能稳住人心。
3. 破格提拔要公开验证，把个人偏好转化为众人认可的结果。
4. 取胜时留余地：杨志"只射他不致命处"，避免把竞争变成仇杀。
5. 派员外出要现场独有的物证（如红叶），比口头汇报可靠。
