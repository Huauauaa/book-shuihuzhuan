# 第九回：柴进门招天下客 林冲棒打洪教头

## Core Idea
真救援要"见彻"——鲁智深一路护到沧州近郊才走；林冲赢洪教头，靠柴进解开"怕打翻师父"的面子结、自己用"只多这具枷"逼出公平条件。到牢城营，规则变成钱与书两条腿：现金买执行者态度，文书买决策者照看。

## Frameworks Introduced
- **"救人须见彻"的全程护送**：解围只是起点，陪到风险消失的地平线。
  - When to use: 护送仍在加害者射程内的人。
  - How: 智深飞禅杖隔棍、割索扶起却不杀公人；一路"要行便行要歇便歇"、讨车将息，直到距沧州七十里"前路都有人家，别无僻静去处"才别，临行打折松树立威。
- **解面子结的激励设计**：看穿对方不出手的真实顾虑，说破并授权。
  - When to use: 能人因顾及关系身份而推辞。
  - How: 柴进道"此位洪教头也到此不多时，此间又无对手，林武师休得要推辞"，再丢下二十五两利物，"只要林冲把出本事来"。
- **以退为进争公平**：先认输让出面子，再把不公平条件变成对方必须修正的问题。
  - When to use: 比试前条件明显不对等。
  - How: 斗四五合后林冲跳出"小人输了"，理由是"只多这具枷"；柴进即取十两银请公人开枷，另设利物。

## Key Concepts
- **小旋风柴进**：柴世宗嫡派子孙，有誓书铁券，专招天下好汉，流配犯人投庄必资助。
- **洪教头**：庄上"教师"，不还礼、上首坐，讽配军"倚草附木"。
- **山东大擂／把火烧天势／拨草寻蛇势**：两人棒法门户与架势，林冲由此看破"步已乱"。
- **利物**：二十五两银，柴进丢在地上激林冲出本事。
- **一百杀威棒**：太祖旧制，新配军须受；有病可"寄下"。
- **钱与书**：林冲给差拨五两、托带十两与管营，再递柴进书；差拨"落了五两"只将五两并书呈管营。

## Mental Models
- 把"救人"看作连续过程：解围只是开始，陪到风险消失。
- 把"不肯出手"看作面子结构问题：解开身份误解比鼓励有效。
- 把"通关"看作钱与书两条腿：现金买态度，文书买照看，预留中间人截留。

## Anti-patterns
- **轻慢的代价**：洪教头不还礼、占上座、讽"配军"，换来"扑地倒了"的羞辱。
- **初入系统不识规矩**：林冲见差拨不拜不呈钱，被骂"贼配军"。
- **好意反而慢客**：柴进初命只拿"一盘肉一盘饼"，被斥"村夫不知高下"。

## Worked Example
鲁智深飞禅杖隔开薛霸水火棍；林冲劝"非干他两个事，尽是高太尉使陆虞候分付"，智深才饶公人，一路护到沧州近郊方别。林冲投柴进庄，柴进滚鞍下马便拜、杀羊置酒；洪教头歪戴头巾挺脯子入来，林冲拜了两拜，他"全不采着，也不还礼"，上首便坐，讥"流配军人倚草附木"。柴进"凡人不可易相，休小觑他"，洪教头跳起要较棒。林冲怕打翻"柴大官人师父"而踌躇，柴进点破"此位洪教头也到此不多时，此间又无对手"，又丢下二十五两利物。林冲使"山东大擂"，斗四五合跳出"小人输了"，只因"多这具枷"；柴进即开枷。再战洪教头使"把火烧天势"盖入，林冲使"拨草寻蛇势"望后一退，见其步乱，一棒跳起扫中臁儿骨，洪教头撇棒扑地倒了。柴进赠书两封、银二十五两，林冲戴枷投沧州。

## Key Takeaways
1. 救援要陪到风险消失，中途放手等于没救。
2. 能人不出手，先问是不是有面子或身份障碍。
3. 条件不公平时，用"认输"把问题交还给出题人。
4. 进入收费型系统，先观察对方发作节奏，再递"薄礼"。
