# 第七十八回：十节度议取梁山泊 宋公明一败高太尉

## Core Idea
蔡京、高俅把童贯惨败改写成"暑热不伏水土"，换帅夺权、水陆并进；吴用看穿十节度"已是背时的人"，先派董平、张清小股截杀"报信"，再在芦苇港汊填断浅港，把官军"两下不能相顾"的计策反过来用。欺君的信息链与轻敌的资历链，共同造成一败再败。

## Frameworks Introduced
- **隐败换帅（欺君的信息链）**：把败仗改写成客观原因，推掉责任、换取全权。
  - When to use: 分析组织为何一错再错时。
  - How: 高俅"只瞒了今上天子便了，谁敢胡奏"；蔡京"折了许多军马，这事怎敢教圣上得知"，教奏"天气暑热，军士不伏水土，权且罢战"；高俅自荐并索"圣旨任便起军，并随造船只……水陆并进"。
- **以老将自恃**：旧日绿林出身、招安至高官的节度使，自恃旧功而轻敌。
  - When to use: 对手资历老、名声大时。
  - How: 吴用"昔日诸葛孔明用三千兵破曹操十万军……那十节度已是背时的人了"；王文德自夸"十节度使累建大功"——话未落音，被董平缠住三十合、张清一石子打中盔顶。
- **先惊后战（小股巡哨报信）**：不等大军会齐，先派猛将截杀挫其锐气。
  - When to use: 敌军远来、需局部胜利镇慑时。
  - How: 吴用"先差两个快厮杀的，去济州相近接着来军，先杀一阵，这是报信与高俅知道"；董平旗写"英雄双枪将，风流万户侯"，号"董一撞"，拦路斗王文德三十合，张清接着一石子打中盔顶。
## Key Concepts
- **十节度使**：王焕、徐京、王文德、梅展、张开、杨温、韩存保、李从吉、项元镇、荆忠。
- **高俅**：隐败欺君、自荐亲征，索"任便起军、随造船只"之权，带歌儿舞女三十馀人随军。
- **刘梦龙**：建康府水军统制，母梦黑龙入腹，统领一万五千水军、五百只船。
- **董一撞**：董平绰号，"梁山泊第一个惯冲头阵的勇将"。
- **呼延灼鞭打荆忠**：一鞭打得"脑浆迸流，眼珠突出"。
- **项元镇背射董平**：拖枪诈败、绕阵脚"翻身背射一箭"正中右臂。

## Mental Models
- 败报可能被权力改写：看清"谁在奏、瞒了谁"，才能理解决策为何越来越错。
- 对手资历老不等于战斗力强：吴用"背时的人"把心理劣势翻转过来。
- 诈败是双向技法：项元镇背射伤董平，呼延灼卖破绽打杀荆忠。

## Anti-patterns
- **欺君瞒败**："只瞒了今上天子""这事怎敢教圣上得知"——错误信息让天子更错。
- **纵兵害民**：军士掳掠，节度使搬门窗搭窝铺；"无银两使用者充头哨，有银两者留中军虚功滥报"。
- **以名号轻敌**：王文德自夸名扬天下，被一石子打中盔顶。

## Worked Example
戴宗、刘唐探知高俅亲征、十节度并水军一十三万来犯，宋江惊恐；吴用却道"那十节度已是背时的人了"，先差董平、张清各带一千人去济州相近"先杀一阵，报信与高俅知道"。凤尾坡林边，董平打出"英雄双枪将，风流万户侯"旗号拦路，与王文德斗三十合不分胜败；王文德冲过林子，张清一石子正中盔顶，王文德伏鞍奔逃。高俅到济州，用王焕之计欲"马步探路引贼出战、水路战船劫巢"。阵前林冲与王焕七八十合不分胜负，呼延灼卖破绽一鞭打杀荆忠；项元镇拖枪诈败、绕阵脚翻身背射，一箭正中董平右臂。高俅挥军混战直赶到水边，刘梦龙的官船却陷在芦苇港汊里——山坡炮响，四面小船冲断大队，浅港被柴草木植填塞，橹桨摇不动；阮氏三雄逼近，张横从水底揪住党世雄丢上芦苇根头，活捉上山。高俅见水路又折，只叫得"苦了也"。

## Key Takeaways
1. 败报可能被权力改写；看清"谁在奏、瞒了谁"。
2. 对手资历老、名声大不等于强；吴用"背时的人"一语翻转心理劣势。
3. 大军未至先派小股截杀"报信"，用局部胜利挫锐气。
4. 敌方水陆并进时先填塞港汊，让船队前后不相救应。
