# 第三十五回：石将军村店寄书 小李广梁山射雁

## Core Idea
名声要靠可验证的表演兑现：花荣当众射中雁行第三只，把"小李广"从传闻变成"神臂将军"。而真正能把亡命者拉回秩序的，是家人伪造的一封急信——孝道比官府通缉更能决定去留。

## Frameworks Introduced
- **官军旗号的迁徙伪装**：把整寨搬迁包装成"收捕草寇官军"，借官方名义过境。
  - When to use: 三五百人携老小车辆长途投奔另一山寨时。
  - How: 宋江教"分作三起下山，只做去收捕梁山泊的官军"，旗号明写"收捕草寇官军"，"因此无人敢来阻当"；先烧山寨做光地，宋江花荣带老小先行，秦明黄信第二起，燕顺王英郑天寿后起。
- **入伙的分批通报**：先派两人报信，大队随后陆续进程，避免被误认为官军。
  - When to use: 对方有哨船探细，而你的队伍规模大时。
  - How: 宋江道"等我和燕顺先去报知了，你们随后却来"；朱贵"讨书札看了，先向水亭上放一枝响箭"报山。
- **当众兑现的技艺展示**：先说出可证伪的具体目标，再一箭命中，把传闻变目击事实。
  - When to use: 名声被怀疑，而现场正好有可验证机会时。
  - How: 晁盖听人说射断绒绦"意思不信，口里含糊应道：'改日却看比箭'"；花荣讨一张泥金鹊画细弓，指雁行说"要射雁行内第三只雁的头上，射不中时，众头领休笑"；一箭正中，众人称"神臂将军"，吴用赞"便是养由基也不及神手"。
- **家书暗号的召回术**：用反常封皮预告噩耗，以不可拒绝的孝道阻断落草。
  - When to use: 家人想阻止亲人入伙，正面劝阻无效时。
  - How: 石勇带来的家书"封皮逆封着，又没'平安'二字"，内称父"正月初头因病身故"；宋江哭得昏迷，"马也不要，从人也不带，一个连夜自赶回家"；宋太公后揭示："我只写道我殁了，你便归来得快……又怕你一时被人撺掇落草去了。"

## Key Concepts
- **小温侯吕方／赛仁贵郭盛**：对影山两个使方天画戟的壮士，红衣红马与白衣白马，为夺山每日厮杀，被花荣一箭射断搅在一起的绒绦。
- **石将军石勇**：大名府人，"靠放赌为生"，赌博打死人逃在柴进庄，为宋清寄家书寻兄。
- **逆封家书**：封皮反写、不写平安，是宋太公报"父丧"的暗记。
- **响箭**：朱贵水亭所放，射过对岸即调船报山。

## Mental Models
- 把"名声"看作需现场证据的资产：指定目标的实射，一次结清转述带来的怀疑。
- 把"礼仪性理由"看作最强约束：宋江能顶住通缉，却无法拒绝"奔丧"。
- 把"哨船+响箭+分批"看作组织准入审核：即便持宋江手书，仍先验再接。

## Anti-patterns
- **据寨恋栈**：清风山众人自知"此间小寨不是久恋之地"，大军围住又无退步。
- **大队叩关**：宋江预判"只道我们来收捕他，不是耍处"，故先派先锋报信。
- **凭转述判断能力**：晁盖不信射断绒绦，不给当场验证的机会，威信就立不起来。

## Worked Example
聚义厅上二十一位头领两行坐定。席间说起花荣一箭射断吕方、郭盛搅在一起的画戟绒绦。晁盖听了"意思不信"，含糊道："改日却看比箭。"当日众人下阶到寨前第三关闲步，正听得空中宾鸿嘹喨。花荣寻思：何不就此施逞手段？便讨过一张泥金鹊画细弓，对晁盖道："小弟这枝箭，要射雁行内第三只雁的头上。射不中时，众头领休笑。"说罢搭箭拽满，望空中一箭射去。那只雁"孤影向云中倒坠"，直落山坡下；军士取来看时，箭"正穿在雁头上"。晁盖与众人尽皆骇然，都称花荣做"神臂将军"；吴学究赞道："便是养由基也不及神手。"自此梁山泊无一个不钦敬花荣。

## Key Takeaways
1. 队伍长途转移，用"官方旗号+分批行进"比藏行踪更省事。
2. 投奔大组织先派先锋报信，即便你持有介绍信。
3. 被疑技能时，提出可验证的目标并当众完成。
