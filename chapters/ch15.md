# 第十五回：吴学究说三阮撞筹 公孙胜应七星聚义

## Core Idea
吴用招募三阮不靠游说而靠需求引导：以买大鲤鱼的无害请求开场，让对方自己说出"梁山泊衣饭被绝"的不满；再用欲擒故纵与道德测试，把抱怨转化为"这腔热血只要卖与识货的"的加入意愿；公孙胜上门凑七星盟誓。

## Frameworks Introduced
- **伪装需求探真话**：用无害、具体的小需求接近目标，把话题引向其真实痛点。
  - When to use: 招揽有本事但不满现状的人，直说劫纲会吓跑对方。
  - How: 吴用自称"大财主家做门馆教学，要十数尾重十四五斤的金色鲤鱼"；夜宿阮家水亭重提"这般大鱼只除梁山泊里便有"，逼出阮小五"在先这梁山泊是我弟兄们的衣饭碗，如今绝不敢去"。
- **欲擒故纵的招募**：先站在劝阻一边，让对方自己争取。
  - When to use: 对方有顾虑、怕被利用，直接邀请反掉价。
  - How: 吴用说"这等人学他做甚么……也是自做的罪"；阮小二偏答"但有肯带挈我们的，也去了罢"，阮小七"水里水里去，火里火里去"。
- **道德测试先行**：先验证底线，再揭示计划。
  - When to use: 吸收成员参与灰色行动，须确认其不反噬同伴。
  - How: 吴用故意说"半路拦住取了"；阮小五答"他既是仗义疏财的好男子，我们却去坏他的道路，须吃江湖上好汉们知时笑话"；吴用方说出晁盖相请。

## Key Concepts
- **石碣村**：梁山泊边，阮氏三兄弟打鱼为生，"亦曾在泊子里做私商勾当"。
- **立地太岁阮小二／短命二郎阮小五／活阎罗阮小七**：三兄弟，"这腔热血，只要卖与识货的"。
- **撞筹**：入伙术语；阮小二顾虑王伦"心地窄狭，安不得人"，林冲上山"呕尽他的气"。
- **入云龙公孙胜**：道号一清先生，蓟州人；能呼风唤雨、驾雾腾云。
- **金钱纸马烧纸**：晁盖为六人聚义所设盟誓，誓词"但有私意者，天地诛灭，神明鉴察"。
- **不义之财**：梁中书"在北京害民，诈得钱物"，送蔡太师庆生辰。

## Mental Models
- 把"招募"看作需求引导：用对方熟悉的小需求开场，让他自己说出痛点。
- 把"劝阻"看作反向筛选：越劝退，越能让真有意者主动证明自己。
- 把"义气"看作可测试的底线：先问"会不会害朋友"，再谈"取不义之财"。

## Anti-patterns
- **直说目的**：一上来便说劫生辰纲，三阮未必肯见；吴用"只做买鱼"才得近身。
- **把不满当同意**：抱怨"绝了衣饭"只是情绪，须经"谁是识我们的"才转化为意愿。
- **以貌取人**：庄客把公孙胜当化缘道士敷衍，与三斗米仍不肯去，几乎误事。

## Worked Example
吴用连夜投石碣村，以"大财主家做门馆、要买十四五斤金色鲤鱼"为由，随阮小二荡船找到阮小七、阮小五，在水阁酒店大块吃牛肉。天晚转到阮小二家后亭，吴用重提大鱼，阮小二叹"这般大鱼只除梁山泊里便有"，阮小五接道"在先这梁山泊是我弟兄们的衣饭碗，如今绝不敢去"——王伦、林冲一伙占了泊子，绝了他们一年多衣饭。吴用不急劝，反说"这等人学他做甚么……也是自做的罪"；阮小二偏说"但有肯带挈我们的，也去了罢"，阮小五"谁是识我们的"，阮小七"水里水里去，火里火里去"。吴用又问"你们敢上梁山泊捉这伙贼么"，阮小七反问"便捉的他们，那里去请赏"。直到阮小五以"坏晁盖道路须吃好汉笑话"表明惜客好义，吴用才实说晁盖相请、共取不义之财，三阮当即立誓；次日到晁家庄，六人列金钱纸马烧纸盟誓，恰好入云龙公孙胜上门，凑成七星。

## Key Takeaways
1. 招募能人先找无害的具体需求做切口，让对方自己说出不满。
2. 越想招揽越要先劝阻；让对方主动证明意愿，承诺才牢。
3. 吸收成员前设一道道德测试，确认底线一致。
4. 行动人数宁少勿杂："人多做不得，人少又做不得"。
