# 第十回：林教头风雪山神庙 陆虞候火烧草料场

## Core Idea
林冲活下来不靠洞察，靠三个偶然与一个习惯：草厅被雪压倒、出门"将火炭盖了"、进庙"掇大石头靠了门"，恰好把纵火者与受害者错开；陆虞候在檐下自道全案，把怀疑变铁证。"太尉差遣"的推诿再次出现时，林冲以"杀人可恕，情理难容"判决背叛——忍让到此终结。

## Frameworks Introduced
- **风险情报的间接获取**：发现可疑人物不当场对质，让可信者偷听、事后转述。
  - When to use: 对方有官身、你无凭证、对质会连累自己。
  - How: 李小二凭东京口音、"高太尉"三字起疑，叫老婆阁后听一个时辰，记下"好歹要结果了他性命"与递金银；却不叫林冲来认——"林教头是个性急的人……须连累了我和你"。
- **"好差使"的逆向信号**：无缘无故的好处恰是加害前奏。
  - When to use: 突然被调去"有油水"的岗位。
  - How: 管营拨林冲管草场称有"常例钱"，林冲疑"却不害我，倒与我好差使"；李小二点破"往常不使钱时不能勾这差使"。
- **自供式确证**：让对方在自以为安全处复述全案。
  - When to use: 怀疑已深但缺直接证据。
  - How: 三人推不开被石头靠住的庙门，檐下自道"这条计好么""点了十来个火把""便逃得性命，烧了大军草料场也得死罪"，林冲方知"若不是倒了草厅，我准定被这厮们烧死了"。

## Key Concepts
- **李小二**：东京受林冲救济的酒生儿，沧州营前开茶酒店，缝补衣物、传关键情报。
- **大军草场**：东门外十五里草料场，林冲替老军看守，有"常例钱"。
- **草厅与火盆**：林冲生火、出门"将火炭盖了"；归来草厅雪压、火种浸灭。
- **古庙**：半里外山神庙，林冲掇大石头靠门，隔墙听自供。
- **解腕尖刀／花枪／酒葫芦**：买刀寻敌、挑葫芦沽酒、挺枪杀敌三道具。
- **"杀人可恕，情理难容"**：林冲对陆谦的判决语，忍让终点。

## Mental Models
- 把"可疑情报"看作需间接获取：当场对质会烧掉证据、连带无辜。
- 把"无故的好差使"看作逆向危险信号，越"抬举"越问为什么。
- 把"幸存"看作偶然与习惯协同：盖火、屋倒、靠门，缺一无听觉证据。
- 把"自供"看作最强证据：让对方在安全错觉下复述计划。

## Anti-patterns
- **危险未除先松懈**：寻陆谦三五日不见，"林冲也自心下慢了"。
- **好意不先算后果**：李小二若叫林冲来对质，"须连累我和你"。
- **落难时失控**：讨酒被拒即挑火炭烧人、枪杆乱打，醉倒雪地被缚。

## Worked Example
李小二凭口音与"高太尉"三字起疑，让老婆隔墙听实告知林冲。林冲认出五短身材的陆虞候，买解腕尖刀寻三五日不见，心下渐慢。第六日管营"抬举"他去大军草场，李小二暗道"往常不使钱时不能勾这差使"。当日彤云密布朔风卷雪，林冲到草厅生火、见屋崩坏，出门沽酒前"将火炭盖了"、反锁门；市井沽酒牛肉而回，见草厅已雪压、火种浸灭，拽絮被投古庙，掇大石头靠门。正吃冷酒，听得外面必必剥剥，草场火起；三人推不开门，檐下自道"这条计好么""点了十来个火把""便逃得性命，烧了大军草料场也得死罪"。林冲掇开石头挺枪拽门，大喝"泼贼那里去"，戳倒差拨、追杀富安，把陆谦踏住，拔尖刀道"我自来又和你无甚冤仇，你如何这等害我！正是杀人可恕，情理难容"，剜心取肝，割三头摆供桌，吃尽冷酒提枪投东。

## Key Takeaways
1. 怀疑未证实，先让信息自己暴露，别急着对质。
2. 意外的"好差使"先问动机，尤其来自正迫害你的人。
3. 琐碎习惯（盖火、锁门）在关键时刻改写命运。
4. "奉命行事"不是免罪符；交情越深，背叛越不可恕。
