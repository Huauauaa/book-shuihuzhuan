# 第五十二回：李逵打死殷天锡 柴进失陷高唐州

## Core Idea
纸面凭据撞上现实权力必碎：柴进守丹书铁券讲"条例"，李逵"若还依得天下不乱了"直接动手，快意的是李逵、下牢的是柴进。本回又用高廉妖法说明：赢一招不等于赢全局。

## Frameworks Introduced
- **前打后商量**：先消除威胁再谈道理，与"依条例打官司"对立。
  - When to use: 对方依仗权势、不认规则，且已"喝令打"时。
  - How: 李逵"条例，条例！若还依得，天下不乱了！我只是前打后商量"；柴进守"护持圣旨""明明的条例"，认"禁城之内如何比得山寨横行"。
- **丹书铁券的层级依赖**：把护身符一层层往上押，却没人接。
  - When to use: 识别"凭据—官府—御前"链条是否被截断时。
  - How: 柴进先"取丹书铁券来和他理会"，再"告到官府今上御前也不怕"；殷天锡"便有誓书铁券我也不怕"，高廉以"抗拒官府"痛打，凭据未到人先下狱。
- **空寨诱敌与妖法辨伪**：用空间事实识破非常规手段。
  - When to use: 敌方呼风唤雨、你连折两阵时。
  - How: 吴用留杨林白胜看寨、余众退旧寨；高廉杀入空寨回身便走，被弩箭射中左肩；又据"只隔五里却无雨无风"断定云雨是"左近水泊摄来的"妖法。

## Key Concepts
- **殷天锡**：高廉妻舅，倚势横行，强占柴皇城花园，被李逵打死。
- **高廉**：高唐州知府、高太尉叔伯兄弟，使太阿宝剑起黑风、聚兽铜牌放猛兽。
- **柴皇城**：柴进叔父，被殷天锡殴打呕气而亡，临终嘱"拦驾告状"。
- **回风返火破阵之法**：宋江天书第三卷所载，念咒捏诀把怪风反吹回去。
- **庄客李大**：柴进替李逵顶罪编的化名，被高廉当场戳穿。

## Mental Models
- 把"丹书铁券"看作纸面权利：对方不认时它只是招祸的纸。
- 把"条例"与"前打后商量"看作两套秩序：前者失灵，后者见效却转嫁成本。
- 把"妖法"看作信息不对称：破解靠反制咒语与"无雨无风"的观察。

## Anti-patterns
- **迷信护身符**：凭据未到就硬顶到"今上御前"，结果挨打、下死囚枷、家私被抄。
- **快意留祸**：李逵打死殷天锡便走，把柴进"陷于缧绁"，宋江听罢"失惊"。

## Worked Example
殷天锡带三二十人佯醉到柴宅，限三日搬出，否则枷号吃一百讯棍。柴进披孝服以"龙子龙孙、先朝丹书铁券"相拒。殷天锡喝"便有誓书铁券我也不怕！左右与我打这厮！"李逵门缝看见，拽开房门大吼一声将他揪下马一拳打翻，打倒五六个，拳头脚尖一发上，片刻打死。柴进催他"快走回梁山泊去，我自有誓书铁券护身"；李逵取双斧走。二百余人围宅缚了柴进，搜黑大汉不见，绑到州衙。柴进称"庄客李大救护，一时行凶打死"。高廉反问"他是个庄客，不得你的言语如何敢打死人！你又故纵他走了"，喝令痛打，打得皮开肉绽，柴进只得招"使令庄客李大打死殷天锡"，钉二十五斤死囚枷下牢。殷夫人又教抄扎家私、监禁人口。

## Key Takeaways
1. 纸面凭据先确认对方认不认；不认时越往上押注越被动。
2. "先打后商量"能解一时之气，成本却转嫁给担保人。
3. 顶罪说辞要经得起反问：临时编的化名一句就穿帮。
4. 面对非常规手段，先用事实辨伪，再设计空营诱敌。
